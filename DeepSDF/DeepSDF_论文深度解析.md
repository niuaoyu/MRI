## 第一部分：论文概述

### 1. 背景、研究目的和问题

**背景**：3D形状表示是计算机图形学、计算机视觉和机器人学的核心问题。现有3D表示方法面临根本性的权衡：

| 表示方法 | 优点 | 缺点 |
|---------|------|------|
| **体素 (Voxel)** | 直观，适合卷积 | 分辨率立方增长 $O(n^3)$，$128^3$ 以上难以处理，细节丢失 |
| **点云 (Point Cloud)** | 轻量，接近传感器原始数据 | 不描述拓扑，无法产生水密表面 |
| **网格 (Mesh)** | 紧凑，适合渲染 | 受限于固定拓扑结构，无法处理任意拓扑 |

**研究目的**：提出一种高效、高保真、**完全连续**的3D形状表示方法，同时满足：
- 复杂拓扑（孔洞、把手等）
- 封闭（水密）表面
- 高质量表面法线
- 极小存储占用

**核心问题**：能否用神经网络直接学习**连续**的有符号距离函数（SDF），从而摆脱离散化带来的精度和分辨率限制？

### 2. 创新点/方法

| 创新点 | 说明 |
|--------|------|
| **连续SDF表示** | 首次用神经网络直接学习连续的、可泛化的3D形状SDF |
| **Auto-decoder 架构** | 抛弃编码器，直接用解码器 + 隐向量优化（decoder-only） |
| **隐空间先验正则化** | 零均值高斯先验迫使隐空间紧凑、完整、可插值 |
| **任意数量输入推理** | MAP估计可以从任意数量的SDF样本中恢复形状，天然支持补全 |

### 3. 主要研究方法

1. **数据准备**：从 ShapeNet 网格中采样空间点 + 计算SDF值（近表面密集采样）
2. **网络架构**：8层全连接网络（FC），512维，Weight-Normalization + ReLU + Dropout，最后一层 tanh
3. **自动解码器训练**：联合优化网络参数 $\theta$ 和每个形状的隐编码 $\{z_i\}$，最大化后验概率
4. **推理（MAP估计）**：固定 $\theta$，通过梯度下降优化 $\hat{z}$ 匹配观测SDF样本
5. **评估指标**：Chamfer Distance、Earth Mover's Distance、Mesh Accuracy / Completion / Cosine Similarity

### 4. 主要发现/结论

- DeepSDF 在已知/未知形状表示上**显著超越** OGN 和 AtlasNet（Chamfer 距离降低 50-70%）
- 仅 **7.4 MB** 存储整个形状类别（如数千个椅子），比单个 $512^3$ 的 3D bitmap（16.8 MB）还小
- 形状补全任务上全面超越 3D-EPN（Mesh completion 率 0.947 vs 0.723）
- 隐空间插值产生有意义的连续形状过渡

### 5. 对该领域的贡献

1. **开创连续隐式3D表示新范式**——后续 NeRF、Occupancy Networks、NeuS 等工作都建立在类似思想上
2. **Auto-decoder 概念的推广**——验证了 decoder-only + 优化比 encoder-decoder 更适合3D形状学习
3. **证明连续表示优于离散表示**——不需要体素化就能表达任意复杂拓扑
4. **综合优势**：同时实现复杂拓扑 + 水密表面 + 高质量法线 + 极小存储

### 6. 局限性

| 局限 | 说明 |
|------|------|
| **推理速度慢** | MAP 优化需要大量迭代（论文报 9.72 秒/形状），AtlasNet 只需 0.01 秒 |
| **需要规范姿态** | 假设物体在规范坐标系中，实际场景需额外优化 SE(3) 变换 |
| **仅静态形状** | 无法处理动态场景和纹理 |
| **训练收敛问题** | VAE 方式训练失败，只能用确定性 auto-decoder |
| **需要水密网格** | 数据预处理需要丢弃非水密网格，限制了数据来源 |
| **缺少法线约束损失** | 论文未显式监督法线一致性 |

### 7. 一句话总结核心价值

> **DeepSDF 用神经网络直接学习连续有符号距离函数，以极小存储实现了高质量、任意拓扑、可插值的3D形状表示，开创了隐式神经表示的新范式。**

## 第二部分：深入技术解析

### 0. 前置概念：什么是有符号距离函数（SDF）？

**直观理解**：想象一个物体（比如一个球），对空间中任意一点 $(x,y,z)$：

- 如果点在物体**外部** → SDF 值 = **正数**（到表面最近距离）
- 如果点在物体**表面** → SDF 值 = **0**
- 如果点在物体**内部** → SDF 值 = **负数**（到表面最近距离的相反数）

```
数学定义：SDF(x) = s, 其中 x ∈ ℝ³, s ∈ ℝ
表面隐含表示为：SDF(x) = 0 的等值面
```

**SDF值是怎么得到的？**  
给定一个水密网格（三角形网格），计算任意点 $x$ 的 SDF 值：
1. 找到 $x$ 到网格上最近的三角形面片，得到欧氏距离 $d$
2. 判断 $x$ 在网格内部还是外部（通过法线点积或射线交叉法）
3. $SDF(x) = \begin{cases} +d & \text{外部} \\ 0 & \text{表面} \\ -d & \text{内部} \end{cases}$

### 2. 每一步的详细处理

#### 模块1：数据准备（SDF采样）

**输入**：ShapeNet 网格文件（三角形网格，每个形状一个 mesh）

**处理流程**：

```
输入 mesh → 归一化到单位球 → 虚拟相机渲染 → 表面点采样 → KD-tree 构建 → 空间点采样 → SDF 计算
```

**详细步骤**：

**Step 1：归一化**
- 将每个 mesh 缩放到**单位球内**（球半径 = 1/1.03 ≈ 0.97）
- 形状的最大尺度 ≈ 1.0（留边距）

**Step 2：表面点采集**
- 在单位球表面均匀放置 **100 个虚拟相机**
- 每个相机渲染深度图，反投影得到表面点
- 每个表面点附带法线（指向相机方向）
- 得到点集 $P_s$：每个点 = (x, y, z, nx, ny, nz)
- **丢弃**双面可见三角形超过 2% 的 mesh（非水密）

**Step 3：KD-tree 构建**
- 用表面点集 $P_s$ 构建 KD-tree，用于快速最近邻查询

**Step 4：空间点采样**（关键：近表面密集采样）

```
总采样点数：500,000

采样策略：
- 250,000 个表面点（按三角形面积加权），
  每个点沿 xyz 轴加高斯噪声（σ²=0.0025 和 0.00025）
  → 生成 500,000 个近表面点
  
- 25,000 个均匀采样于单位球内
  
合计：~525,000 个点
```

**Step 5：SDF 值计算**  
每个采样点 $x$：
1. 在 KD-tree 中找最近表面点 $p$
2. 计算欧氏距离 $d = \|x - p\|$
3. 符号判定：$sign = \text{sign}((x-p) \cdot n_p)$
4. $SDF(x) = sign \times d$

**输出**：$X = \{(x_j, s_j)\}$，其中：
- $x_j \in \mathbb{R}^3$（3D空间坐标）
- $s_j \in \mathbb{R}$（SDF值，标量）
- 每个形状 500,000 个样本点
- 数据总量：$N \times 500{,}000 \times 4$ 个浮点数

**为什么这样设计？**
- **近表面密集采样**：SDF=0 的等值面是我们要的表面，近表面区域需要高精度
- **均匀采样**：确保网络不能只"记住"近表面区域，需要理解全局场
- **丢弃非水密 mesh**：非水密 mesh 的 SDF 值无法定义（内部/外部不明确）

**关键超参数**：

| 参数 | 重建实验 | 补全实验 |
|------|---------|---------|
| 隐编码维度 | 256 | 128 |
| Batch 内形状数 $B$ | — | — |
| 每形状 SDF 样本数 | 16,384 | 16,384 |
| Decoder 学习率 | $10^{-5} \times B$ | $10^{-5} \times B$ |
| 隐编码学习率 | $10^{-3}$ | $10^{-3}$ |
| 正则化系数 $\sigma$ | $10^{-2}$ | $10^{-2}$ |
| 截断距离 $\delta$ | 0.1（单形状）/ 0.01（多形状） | 0.01 |
| 优化器 | Adam | Adam |
| 训练设备 | 8×NVIDIA GPU | 8×NVIDIA GPU |
| 训练时间 | ~8小时（1000 epochs） | ~8小时 |
| 隐编码初始化 | $\mathcal{N}(0, 0.01^2)$ | $\mathcal{N}(0, 0.01^2)$ |

**损失函数**：

$$
\mathcal{L}(f_\theta(\boldsymbol{x}), s) = |\text{clamp}(f_\theta(\boldsymbol{x}), \delta) - \text{clamp}(s, \delta)|
$$

其中 $\text{clamp}(x, \delta) = \min(\delta, \max(-\delta, x))$

**训练总目标**：

$$
\argmin_{\theta, \{z_i\}} \sum_{i=1}^N \left( \sum_{j=1}^K \mathcal{L}(f_\theta(z_i, x_j), s_j) + \frac{1}{\sigma^2}\|z_i\|_2^2 \right)
$$

- 第一部分：SDF 预测误差 → 控制重建质量
- 第二部分：隐编码 L2 正则化 → 控制隐空间紧凑性（先验）

#### 模块3：跳过连接（Skip Connection）

**为什么在第4层后重新拼接 z 和 x？**

> **原因**：随着网络加深，隐编码信息在前向传播中逐渐衰减——称为"信息衰减"问题。

**效果**：
- 无跳过连接：4层后训练损失停滞
- 有跳过连接：损失继续下降（16层比8层更好）
- 论文 Fig. capacity 显示：无跳过连接时4层就饱和，加跳过连接后16层仍有提升

#### 模块4：推理阶段（MAP 优化）

```
                   推理流程（针对新形状）

输入：部分观测（例如单视角深度图）
                   
Step 1: 从观测生成 SDF 样本
  ┌─ 深度图 ─→ 反投影 → 3D点云
  └─ 每个表面点沿法线偏移 ±η → 两个 SDF 样本
     (s ≈ +η 和 s ≈ -η)
  └─ 自由空间采样：相机到表面之间的点 → s > 0 约束

Step 2: MAP 优化
  初始化 z ∼ N(0, 0.01²)
  for iteration = 1..800:
      ŝ_j = f_θ(z, x_j)         # 前向传播
      L = |clamp(ŝ_j, η) - clamp(s_j, η)| + (1/σ²)||z||²₂
      z = z - lr × ∇_z L        # 只更新 z，固定 θ

Step 3: 表面提取
  对空间均匀网格点查询 SDF 值
  Marching Cubes 提取 SDF = 0 的等值面

输出：完整 3D 网格
```

**推理阶段的关键特性**：
- 输入可以是**任意数量**的 SDF 样本（从1个到百万个）
- 因为是逐点损失求和，梯度计算独立于样本数量
- 天然支持部分观测 → 形状补全

**为什么这种方法优于编码器？**
- 编码器需要完整的输入（固定维度），无法处理部分数据
- MAP 优化天然适合增量式观测（类似 SLAM）
- 编码器训练时从未见过部分数据，而 MAP 优化不依赖训练数据分布

### 3. Auto-decoder vs Auto-encoder 对比

```
Auto-encoder:
    输入 → [编码器] → z → [解码器] → 输出
    编码器学会将完整输入"压缩"到 z
    
问题：编码器在推理时被丢弃（很多工作只用解码器）+ 
      编码器需要固定维度的完整输入 + 额外参数量

Auto-decoder (DeepSDF):
    z 随机初始化 → [解码器] → SDF 值
    没有编码器，z 在训练时作为参数一起优化

优势：
    ✅ 更高效利用参数（注意力全在解码器）
    ✅ 推理时 z 可通过优化任意数量观测获得
    ✅ 隐空间更平滑（先验正则化）
    ✅ 天然支持部分/噪声观测
```

**为什么 VAE 训练不好？**

> 论文原文：*"we found that the stochastic nature of the VAE optimization did not lead to good training results"*

VAE 的随机采样导致 SDF 回归不稳定，确定性 auto-decoder 收敛更好。

### 4. 完整数据流转示例

以一个椅子为例，走一遍完整流程：

```
1. 原始数据
   椅子 mesh（约 10,000 个三角形面片）
   ↓

2. 归一化
   缩放到单位球内（半径 ≈ 1.0）
   ↓

3. 表面采样
   100 个虚拟相机 → 500,000 个表面点（带法线）
   → KD-tree 建立
   ↓

4. 空间点采样
   250,000 个表面点 + 扰动 → 500,000 个近表面点
   25,000 个均匀采样
   合计 525,000 个点
   ↓

5. SDF 计算
   每个点查找 KD-tree → SDF 值
   输出：525,000 × (x,y,z,s) = 525,000 × 4 = 2,100,000 个 float
   ↓

6. 训练（每 batch）
   B=4 个椅子，每个 16,384 个 SDF 样本
   输入：4 个 z（256 维）+ 4×16,384 个 x（3 维）
   前向：65,536 次网络前向 → 65,536 个 ŝ
   损失求和 → 反向传播更新 θ 和 z
   ↓

7. 训练完（1000 epochs）
   网络参数 θ ≈ 2.04M 参数 ≈ 7.4 MB（float32）
   每个椅子有一个 z ∈ ℝ²⁵⁶
   ↓

8. 推理（新椅子）
   给定部分深度图 → 10,000 个 SDF 样本
   初始化 z ∼ N(0, 0.01²)
   800 次迭代优化 z（固定 θ）
   在 256³ 网格上查询 SDF 值
   Marching Cubes 提取表面
```

### 5. 每个模块的设计意图深度分析

#### Q1: 为什么要用 SDF 而不是 occupancy？

| SDF（本文） | Occupancy（传统体素） |
|------------|-------------------|
| 回归问题（连续值） | 分类问题（0/1） |
| 表面附近的渐变信息丰富 | 只有是否占据 |
| 法线可通过解析梯度 $\partial f_\theta / \partial x$ 计算 | 法线粗糙（8方向） |
| 支持 ray-casting 快速渲染 | 需要体素渲染 |

**论文原文**：
> *"a learned continuous Signed Distance Function (SDF) representation of a class of shapes that enables high quality shape representation"*

#### Q2: 为什么 auto-decoder 不用编码器？

**三个原因**：

1. **参数效率**：编码器在推理时被丢弃，浪费计算资源
2. **处理部分观测**：编码器需要固定维度的完整输入；auto-decoder 可以处理任意数量的 SDF 样本
3. **隐空间质量**：auto-decoder + L2 正则化产生更平滑的隐空间，适合插值

**论文原文**：
> *"However, since the trained encoder is unused at test time, it is unclear whether using the encoder is the most effective use of computational resources during training."*

#### Q3: 为什么跳过连接在第4层拼接隐编码？

**解决信息衰减问题**：随着网络加深，$z$ 的信息在逐层变换中逐渐衰减。实验（Fig. capacity）显示不加跳过连接时4层就饱和了，加了之后16层仍有提升。第4层是个平衡点——网络已经学了一些几何特征，此时重新注入 $z$ 有助于后续层继续利用全局形状信息。

#### Q4: 为什么用 clamp L1 而不是 L2 损失？

**L2 损失**对大误差惩罚过重，SDF 值在表面附近很小但在远处很大，L2 会让网络过度关注远处点而忽略近表面精度。

**clamp L1**：
- 截断 $\delta$ 范围内的 SDF 值才有监督信号
- 网络容量集中在表面附近的精确重建
- 远处点只产生"外部"这个分类信号（不要求距离精确）

#### Q5: 为什么采样策略如此重要？

**近表面密集采样 + 均匀采样 = 双保险**
- 近表面采样 → 高精度零等值面（视觉质量）
- 均匀采样 → 全局场理解（避免局部极小值）

如果只采样表面附近，网络可能产生不合理的全局场（例如内部空洞）。

#### Q6: 为什么单形状用 $\delta=0.1$，多形状用 $\delta=0.01$？

单形状时网络可以"记住"更大范围的 SDF 场，因为参数都用于一个形状。多形状时需要共享参数，更小的 $\delta$ 让网络集中资源在表面附近，减少跨形状的冲突。

**论文原文**：
> *"Larger values of δ allow for fast ray-tracing... Smaller values of δ can be used to concentrate network capacity on details near the surface."*

| 模块 | 当前设计 | 替换为传统方法 | 后果 |

## 第三部分：模块级测试题

### 🌱 基础层（Factual Knowledge）

**Q1**: DeepSDF 的输出是什么？输入是什么？

> **A1**:  
> **输入**：3D查询点坐标 $x \in \mathbb{R}^3$ 和（可选的）形状隐编码 $z \in \mathbb{R}^{256}$  
> **输出**：该点的有符号距离值 $s \in \mathbb{R}$（标量，经过 tanh 映射到 [-1, 1]）

**Q2**: DeepSDF 用了几层全连接网络？每层维度是多少？

> **A2**: 8层全连接网络（FC），所有内部层维度为512。最后一层输出为1维（SDF值）。除了第4层和第8层，每层后都接 Dropout (0.2)。第4层后有一个跳过连接重新注入 (z, x)。

**Q3**: 训练数据中每个形状采样了多少个 SDF 点？怎么分布的？

> **A3**: 约 500,000 个点。其中大部分（约 250,000 个表面点经过高斯扰动生成约 500,000 个近表面点）集中在表面附近，约 25,000 个均匀采样于单位球内。

### 🌿 理解层（Comprehension）

**Q4**: DeepSDF 训练时，哪个损失函数控制隐空间的质量？

> **A4**: 正则化项 $\frac{1}{\sigma^2}\|z_i\|_2^2$。它迫使隐编码靠近原点（零均值高斯先验 $p(z) = \mathcal{N}(0, \sigma^2 I)$），从而让隐空间紧凑、连续、无空洞，支持平滑插值。**论文原文**：*"This prior encapsulates the notion that the shape codes should be concentrated and we empirically found it was needed to infer a compact shape manifold and to help converge to good solutions."*

**Q5**: MAP 推理时，为什么可以用任意数量的 SDF 样本？

> **A5**: 因为损失函数 $\sum_j \mathcal{L}(f_\theta(z, x_j), s_j)$ 是逐点求和形式，梯度 $\nabla_z$ 也是逐点计算的和。样本数可以任意（1到百万），不影响优化框架。**论文原文**：*"Crucially, this formulation is valid for SDF samples X of arbitrary size and distribution because the gradient of the loss with respect to z can be computed separately for each SDF sample. This implies that DeepSDF can handle any form of partial observations such as depth maps."*

**Q6**: 为什么 DeepSDF 只需要 7.4 MB 却能表示整个类别的形状？

> **A6**: 2.04M 网络参数编码了该类形状的"通用先验"——比如椅子的基本结构（坐面、靠背、腿的常见规律），每个具体形状只需要 256 维的隐编码（≈1 KB）。对比之下，一个 $512^3$ 体素需要 $512^3 = 134M$ 个体素单元，即使二值化也需要 16.8 MB——这只表示**一个**形状。DeepSDF 用共享知识（网络参数）+ 少量个性化信息（隐编码）实现了极大压缩。

### 🌳 应用与分析层（Application & Analysis）

**Q7**: 假设你在训练 DeepSDF 时发现 loss 不下降但 z 的范数在增大，最可能的问题是什么？怎么解决？

> **A7**: 隐编码过拟合——网络在"记住"每个形状ID而不是学习几何先验。解决：  
> 1. 增大正则化系数 $\sigma$（或减小 $1/\sigma^2$ 权重）  
> 2. 减小隐编码初始化尺度（如 $\mathcal{N}(0, 0.001^2)$）  
> 3. 检查是否 batch 内每个形状的 SDF 样本数太少（论文使用 16,384）  
> 4. 检查正负样本是否平衡（论文要求每batch正负各半）

**Q8**: 如果要将 DeepSDF 用于实时机器人抓取（需要快速推理），什么模块会成为瓶颈？如何改进？

> **A8**: MAP 推理是瓶颈（论文报 9.72 秒/形状）。改进方案：  
> 1. 用 Gauss-Newton 替代 Adam（论文直接建议：*"We look to increase performance by replacing ADAM optimization with more efficient Gauss-Newton or similar methods"*）  
> 2. 训练一个"编码器"作为 z 的初始猜测（warm-start）  
> 3. 用多层感知机 + 超网络方法（如 HyperNetwork）直接预测 z  
> 4. 在嵌入空间上用最近邻搜索替代完整优化

**Q9**: 为什么用 tanh 作为输出激活函数而不是 ReLU 或 linear？

> **A9**: 因为 SDF 值理论上可以无限大（远处点），但 tanh 将输出限制在 [-1, 1]，配合 clamp L1 损失，能有效防止网络在远处无意义区域浪费容量。如果直接用 linear，网络需要学习极大的 SDF 值范围，参数效率低。如果只用 ReLU（非负），无法表示内部（负值）——这就失去了 SDF 的核心优势（区分内外）。

### 🌲 评价与创造层（Evaluation & Synthesis）

**Q10**: DeepSDF 的 auto-decoder 相比 VAE 有什么根本缺陷？什么场景下 VAE 会更好？

> **A10**: Auto-decoder 没有先验分布采样能力——你不能从隐空间中"采样"一个随机新形状（因为没有学习到分布 $p(z)$），只能插值已有形状。VAE 学习了 $p(z)$ 和 $p(x|z)$，可以直接采样生成无限新形状。如果需要**生成式模型**（随机生成新椅子），VAE 更合适。DeepSDF 更适合**重建/补全**任务。论文在 MNIST 实验中也确认了这一点：VAE 的采样质量优于 auto-decoder。

**Q11**: 怎么设计实验证明 DeepSDF 的隐空间是"可解释的"？

> **A11**: 做线性插值实验：取椅子 A 的 $z_A$ 和椅子 B 的 $z_B$，取 $z = \alpha \cdot z_A + (1-\alpha) \cdot z_B$，对 $\alpha = 0, 0.1, 0.2, ..., 1.0$ 分别渲染输出形状。如果输出形状平滑地从 A 过渡到 B（椅子靠背逐渐变化、扶手出现/消失），就证明隐空间是连续的、可解释的。论文 Fig. teaser 展示了这个实验，显示隐空间中存在"椅子手臂"的可解释方向。

**Q12**: DeepSDF 说自己的模型是"continuous"，这和数学上的"连续"完全一致吗？有什么限制？

> **A12**: 理论上神经网络（ReLU网络）学习的是分段线性函数，对 SDF 的近似在数学上是连续的（因为 ReLU 网络是连续函数），但有三个实际限制：  
> 1. **精度有限**：有限参数 → 有限精度（不是真正的任意精度）  
> 2. **tanh 饱和**：输出被限制在 [-1, 1]，对 $\delta > 1$ 的区域截断  
> 3. **Marching Cubes 离散化**：渲染时需要离散化网格（论文用 512³）  
>
> 所以"连续"是指**表示空间连续**——可以查询任意 3D 点，不像体素只能在网格点查询，而非数学上的"任意精度逼近"。**论文原文**：*"As a universal function approximator, deep feed-forward networks in theory can learn the fully continuous shape functions with arbitrary precision. Yet, the precision of the approximation in practice is limited by the finite number of point samples that guide the decision boundaries and the finite capacity of the network."*

## 附录：完整推理例子

### 用一个椅子的单视角深度图做形状补全

```
输入：深度图 (640×480 像素, 每个像素 = 距离值)
  ↓
Step 1: 从深度图生成 SDF 样本
  反投影每个有效像素 → 3D 点云 (约 100,000 个点)
  对每个表面点 p 沿法线 ±η 采样:
    p + η·n → SDF ≈ +η
    p - η·n → SDF ≈ -η
  自由空间点: 相机→p 路径上的点 → SDF > 0 约束
  ↓
  得到: { (x₁, s₁), (x₂, s₂), ..., (x_M, s_M) }，M ≈ 200,000
  ↓
Step 2: MAP 优化
  初始化 z ∈ ℝ¹²⁸ ∼ N(0, 0.01²)
  
  Loop 800 次:
    对每个 (x_j, s_j):
      ŝ_j = f_θ(z, x_j)        # 前向: 维度 128+3=131 → ... → 1
      ℓ_j = |clamp(ŝ_j, η) - clamp(s_j, η)|
    总损失 = Σℓ_j + (1/σ²)||z||²
    z = z - 1e-3 × ∇_z(总损失)
  ↓
  得到最优 ẑ ∈ ℝ¹²⁸
  ↓
Step 3: 表面提取
  创建 256×256×256 均匀网格
  对每个网格点 x:
    s = f_θ(ẑ, x)              # 查询 SDF 值
  得到 256³ 的 SDF 体数据
  Marching Cubes 提取 SDF = 0 等值面
  ↓
输出：完整 3D 三角网格（水密，含法线）
```

> 这个例子中，从约 100,000 个 3D 点（深度图）→ 200,000 个 SDF 样本 → 128 维隐编码 → 完整 chair mesh。整个过程中，网络自动"补全"了深度图没看到的背面、内部结构。（原论文 Fig. completion 展示了实际结果）

## 实验评估指标定义

| 指标 | 定义 | 方向 |
|------|------|------|
| **Chamfer Distance (CD)** | $\sum_{x \in S_1} \min_{y \in S_2} \|x-y\|_2^2 + \sum_{y \in S_2} \min_{x \in S_1} \|x-y\|_2^2$，30,000点 | 越低越好 |
| **Earth Mover's Distance (EMD)** | 最优双射 $\phi: S_1 \rightarrow S_2$ 下的 $\sum \|x - \phi(x)\|_2$，500点 | 越低越好 |
| **Mesh Accuracy** | 90% 生成点在 $\leq d$ 内到 GT mesh 的 $d$ | 越低越好 |
| **Mesh Completion** | GT 点在 $\Delta=0.01$ 内到生成 mesh 的比例 | 越高越好 |
| **Cosine Similarity** | GT法线与最近生成面片法线的平均余弦相似度 | 越高越好 |
