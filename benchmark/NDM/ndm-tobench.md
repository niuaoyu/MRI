## 梳理
NDM 全流程：稀疏轮廓 → 粗心脏 → 精细 mesh

核心思想：所有心脏都从同一个「超二次曲面」出发，先用全局参数摆成粗心脏，再用一个由病例向量 z 控制的神经速度场、经 ODE 积分把每个点「流」到精细位置。

NDM = 橡皮超二次曲面模具，可变形超二次曲面 + 全局参数 + 局部 ODE 流，先平移 / 旋转 / 缩放摆正、再调全局形状、最后用 ODE 局部流捏细节；NDM 输入稀疏心脏轮廓点，先用**点云编码器**预测**全局形状参数和局部形变特征**。全局参数控制**超二次模型**的大小、姿态和整体形状，得到粗心脏。然后一个由病例特征控制的**神经速度场**，告诉每个点怎样移动，通过 ODE 积分得到精细表面。训练时用几何拟合和正则，并由整体到局部逐步训练。对应来自共享模板身份
点云 → PT → z → q_g → s_g → ODE 积分 → Q'，粗心脏是ode的起点，控制速度场的是向量z。


高分辨率扫描 `1.25×1.25×2 mm³`，想象成一个方格空间，长宽都是1.25，高是2mm，在这个空间里像素都一样，然后有很多大概512 * 512* 512这么多的像素块构成了这个像素立方体，之所以高分辨率，一般cmr层间距是8-10mm这里的是2mm所以是高分辨率。**怎么从高分辨率 3D 扫描得到“稀疏输入”和“密集真值”**？因为原始数据有标注，所以对每个3d像素都可以分成0 lv endo、1 lv epi、2 rv 、3 背景，然后根据一些算法提取出来等值面然后marching cube得到致密的mesh网格，也就是gt，对于稀疏输入，就直接短轴切10个，长轴切3个，切面的像素点提取出来得到3d像素空间，因为数量不固定，所以用fps最远采样方法，固定采样5600个点，当做稀疏输入 




固定模板（超二次曲面材料），所有人共享，同一个（u、v、w）在每个病人都是一个点（能做密集对应），但具体是否为是真的解剖点，要靠**注册指标验证**？什么是注册指标？

点云编码器为什么能预测全局参数和局部特征？只要是这种问题都是损失来逼的，但是有个问题是问什么当前框架这个方法好？这需要看很多模块，来做个总结。
pt encoder（点云注意力），把当前点跟周围点做自注意力，学习感知当前层的轮廓多大，朝哪弯，层间距多少？这就是局部信息汇总，接着做gap全局池化，把所有点的特征平均到一个向量z，这个z压缩了整个心脏的信息（大小，姿态，胖瘦，弯曲），==这个维度够不够？猜测应该是测出来的，平衡训练成本和效果，可能256刚好训练时间短的同时效果跟512的差不多==，池化完的向量z拿来做mlp回归的得到全局参数q_g，全局参数好与不好也是损失来管的，数千次训练后，就能知道某个心脏的特征向量z输进来，就能得到一个较好的q_g（包含了，c,R,a0,a,offset整体缩放，三个轴的长宽比......）


全局变形参数qg=c+Rs+d
	c：平移向量，3D
	R：旋转矩阵，3×3，论文用单位四元数表示
	s：形状基元（经过全局变形后的，这里的s就是线代里的那个空间球的坐标表示，只不过a0-a3都是参数函数而不是单纯的数字，这样就可以**让一个简单的椭球，能表达出心脏那种“心尖细、基底粗”的形状**）
	d：局部变形
axis-offset（让长轴弯曲），对长轴上的某个点，在xoy平面上做个偏移，就做到了让长轴弯曲了


基元 e (由材料坐标和初始参数决定)，应用 q_g（一些参数， 是数字是函数，c + R · T_o(e; e_xo, e_yo)）得到粗心脏s_g(B, N_prim, 3)，s_g是3d上的点，是几何形状！



神经速度场，速度场 v(x;z) 本身就是一个小 MLP（NODE 块）输入：点当前位置 x + 病例向量 z；输出：一个 3D 速度向量（往哪、多快）。每个病人的特殊的心脏向量z是开关，输入不同病人的z和**相同粗心脏的点x**就能得到专属该点的速度场 v(x;z) 返回该点的移动方向和速度
速度场是一个神经网络，输入点的当前位置，输出“该往哪走、走多快”。训练时，让点按速度场漂移，比较最终位置和 GT，误差反传，网络就学会了“怎么推点才能到目标”。微分（ODE 求解）只是模拟这个过程：一步步查速度场，一步步移动。最终，速度场自己变成了“目标吸引场”，不管起点在哪，点都会漂到目标附近。

MLP（Multi-Layer Perceptron）就是最普通的神经网络：输入 x → 线性层 → 激活函数 → 线性层 → 激活函数 → ... → 输出 y
- **线性层**：矩阵乘法 + 加偏置。
- **激活函数**：ReLU、Sigmoid、Tanh 等，引入非线性。
- **输出**：可以是标量、向量、参数等。
**MLP 的本质**：一个**万能函数逼近器**。理论上，足够大的 MLP 可以逼近任何连续函数。1. **通用性**：可以拟合任意函数，不需要手工设计公式 2. **可微性**：可以用反向传播训练，端到端优化。3. **简单**：实现容易，计算高效。
MLP 不是万能的，有几个局限：
1. **没有空间/序列结构**：MLP 把输入当成一个扁平向量，不考虑点与点之间的关系。所以点云处理要用 Point Transformer，而不是纯 MLP。 
2. **没有物理约束**：MLP 可以拟合任意函数，但不保证输出满足物理规律。比如，MLP 预测的变形场可能不连续、不可逆、自交。所以 NDM 用 NODE 来保证微分同胚。
3. **数据需求大**：MLP 参数量大，需要大量数据训练。


MLP 不直接输出最终位置。MLP 输出的是**当前位置下的速度**。点移动一小步后，位置变了，再问 MLP 新的速度。反复问，反复走，直到到达终点。**最终位置不是 MLP 直接给的，而是“问路 + 走路”的结果。**

修正后：
$x_0 = s_g，z，t=0→ MLP → v_0$
$v_0，\Delta t，x_0 → ODE → x_1$
$x_1 ，z，t=\Delta t→ MLP → v_1$
$v_1，\Delta t，x_1 → ODE → x_2$
$x_2 ，z，t=\Delta t→ MLP → v_2$

MSL边际空间学习 最核心的痛点：**前面学的参数，在后面参数加入后，还能不能保持“好”？** 如果前面学的是“在后续参数固定下的最优”，那后续参数一放开，前面学的可能就白学了。阶段 1 的 c,R 可能只是“在错误假设下的局部最优”，放开a0后，c,R 需要大改，那阶段 1 的训练就浪费了。这个担忧是对的。 这里MSL 就像画画：
先画轮廓（c,R）：确定位置和朝向。姿态，决定心脏在哪、朝哪。
再画大小（a0）：确定整体尺寸。决定心脏多大
再画胖瘦（a1,a2,a3）：确定比例，纵横比，决定心脏胖瘦。
再画弯曲（ex0,ey0）：确定姿态细节。轴偏移，决定心脏弯曲。
最后画细节（qd）：添加纹理和局部特征。
前面先把相对稳定、粗粒度的参数（姿态 c,R）学出来，再逐步加入更细粒度的参数（a0,a1,a2,a3,e,qd)。**因为粗粒度参数的“大致正确”不依赖于细粒度参数的精确值**，所以前面学的可以作为后面好的初始化。每一步都联合优化已加入的参数，前面学的可以继续微调，不会白学。

数据输入：原始数据有标注，所以对每个3d像素都可以分成0 lv endo、1 lv epi、2 rv 、3 背景，然后根据一些算法提取出来等值面然后marching cube得到致密的mesh网格，也就是gt，对于稀疏输入，就直接短轴切10个，长轴切3个，切面的像素点提取出来得到3d像素空间，因为数量不固定，所以用fps最远采样方法，固定采样5600个点，当做稀疏输入 

模型训练，通过输入的（b,5600,3）个点到pt编码器得到该心脏的特征向量z（256），然后分成三个分支到lv endo lv epi rv 分别通过**PT 解码器生成的是 5000/5500/5000 个基元点（模板上采集的）的特征维度是 (B, N_prim, C')**。这个c‘维度不确定，然后送到全连接层mlp预测全局参数qg，**包含平移 c、旋转 R、尺度 a_0、纵横比函数 a_1, a_2, a_3、轴偏移函数 e_xo, e_yo。** 拿到**全局变形参数向量**qg来对基元（超二次曲面）进行变形得到粗心脏sg，然后sg+心脏特征z+时间t送到mlp预测得到该点的速度v1，然后速度v1+x0=sg+t=0开始计算下一个变化的位置是x1，然后x1，t，z送到mlp预测下一个速度，循环往复，不断计算损失，这里损失有三项，第一项是chamfer（预测q'和gt）很好理解看几何的相近与否，第二项是ld（q‘和sg）的距离，要控制具备微调的时候不要变化太大，要强迫搭建骨架的粗心脏时候，pt解码器多做好事情，让骨架足够好，然后微调的时候可以少动一些，第三项是ls（计算q‘和sg的梯度变化）要控制相邻位置之间的点变化要足够平滑，不能一个跑了100mm，一个就走了1mm，这样不平滑有突刺，反向优化训练，同时采用 MSL（边际空间学习），**逐步扩展参数空间**。先只学 `c, R`，然后加入 `a_0` 一起学，再加入 `a_1, a_2, a_3` 一起学，再加入 `e_xo, e_yo` 一起学，最后加入 `q_d` 一起学。**每一步不是固定前面的参数，而是联合优化所有已加入的参数**。前面学的作为初始化，后面继续更新。
