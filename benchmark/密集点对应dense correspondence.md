
为什么需要点对应？要做统计，让医生判断大众心脏大概是个什么水平，然后就知道某个具体的病人这处的心脏是否有问题


密集对应（dense correspondence）= 让不同心脏上「同一个解剖位置」的点能互相找到。对应点具有相同的解剖语义，“**A 心脏上的这个解剖位置，在 B 心脏上在哪里？**”，判断一个方法能不能建密集对应，只看一条硬标准：它有没有一个所有形状共享、且固定不变的「参数身份」（模板顶点编号 / 模板 UV 坐标 /canonical 模板坐标）

1. 有的话，那么密集对应是「免费副产品」：同一个编号 / 坐标的点，在每个形状上天然对应（模板形变族）。
2. 没有，只有每个形状各自的 latent code → 生成模型再强也不直接给点对点对应（DeepSDF、3DShape2VecSet）。
3. 不预设参数域、事后再匹配 → 靠特征 / 谱 / 配准把点对上（函数映射、配准族）。

有模具、有编号，就能对应；只有密码本、没有编号，就对应不了；不想建模具，就事后匹配。


工程上几乎总是通过一个共享的规范域（canonical domain）（模板表面 / 模板体 / 单位球）来实现：学习每形状一个形变，对应关系是即「先回到模具编号，再到另一个形状」。

可以用在跨受试者，不同病人之间做映射，也可以跨时相，一个病人的ed，es或者逐帧轮廓，或者跨模态，ct，超声等不同的数据之间做对比。现在的 bench 只评几何（ASSD / Chamfer / HD95）—— 回答「形状像不像」；

**模板形变族**天然满足（MR-Net / NDM / DIF-Net / DIT / NDF：顶点或模板坐标就是身份）；
**直接重建族**需要额外接一个「模板 /warp 头」（ONet / DeepSDF / 3DShape2VecSet：目前只有几何、没有身份），这本身就是一个明确的改进方向（hybrid：隐式几何 + 显式对应）。



**人工标注的是 2D 轮廓 / 分割掩膜**（每层切片上描 LV/RV 边界）—— 这部分是真的人工标注；
**3D mesh 没有人标注**：一个病人只有 8–12 层、层间约 10 mm 空隙，连不成完整 3D 心脏，于是用 SSM 拟合轮廓、补全层间，拟合结果才被当作 GT mesh。这就是gt，不是真的而是拟合的，只是对SSM/PCA/DG 族这类的方法要标记清楚循环比较（circular comparison）= 出题和答题用同一套模型，自己和自己比。

**怎么评估密集对应？** 把病人的数据映射到gt上，再gt上做误差分析，还有一些其他办法，直接在两个病人之间的表面计算。

**我现在能重建心脏形状，怎样进一步知道不同心脏、不同心动时相之间“哪个点对应哪个点”？** **重建指标好，不足以证明对应正确；对应看起来平滑，也不足以证明是真实材料运动**


心肌运动：舒张末期的这块心肌组织，收缩后去了哪里？这比几何匹配更强，**最近的表面点，不一定是同一个组织点。**



DeepSDF = 密码本，一个形状一个密码 z，同一个网络输密码 + 坐标，返回 SDF，没有编码器的自解码器训练，每次训练同时优化隐码latent code（全局共用） 和模型函数，训练得到sdf值，后续测试时，一个新的形状，通过高斯分布生成一个隐码，并固定模型参数，进行反向优化出隐码，然后通过隐码输入到模型得到距离函数sdf，通过marching cube生成mesh。这里没有密集对应关系，每个形状都有自己的隐码code，**dif-net就是在deepsdf上加「模板 + 形变」来补上对应**



NDM = 橡皮超二次曲面模具，可变形超二次曲面 + 全局参数 + 局部 ODE 流，先平移 / 旋转 / 缩放摆正、再调全局形状、最后用 ODE 局部流捏细节；NDM 输入稀疏心脏轮廓点，先用**点云编码器**预测**全局形状参数和局部形变特征**。全局参数控制**超二次模型**的大小、姿态和整体形状，得到粗心脏。然后一个由病例特征控制的**神经速度场**，告诉每个点怎样移动，通过 ODE 积分得到精细表面。训练时用几何拟合和正则，并由整体到局部逐步训练。对应来自共享模板身份，但要另行验证其解剖准确性。



MeshDiffusion = 固定四面体骨架



3DShape2VecSet = 悬浮喇叭团，形状 = 一袋向量，注意力查在不在里面



MR-Net=GCN 三捏模板，PointNet 编码 + GCN 逐级形变参考心脏 mesh，先有标准心脏，只学"每顶点挪多少"


模板法换来对应，代价是拓扑受限；场法和生成法换来拓扑自由
