ED / ES 怎么办？

现在先ED + ES 一起实验。不要一开始拆成两个完全独立实验。原因很简单，最终研究的是cardiac reconstruction，而不是ED reconstruction / ES reconstruction 两篇论文
实验中可以Overall、ED、ES分别报告。如果最后发现ED效果很好，ES明显下降，那么这反而可能成为你的 research finding



模型参数量、推理时间需要吗？需要，但不是核心指标。

主指标Geometry：CD、HD / HD95、ASSD、Dice、Volume Error
如果涉及 correspondence：Correspondence Error、Registration Error
辅助：Training time、Inference time、GPU memory

论文里放：Efficiency / Computational Cost即可
