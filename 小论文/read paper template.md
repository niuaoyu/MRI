

### 第一阶段：3个核心问题（建立感官认知）

| 问题         | 要问什么           | 示例答案                   |
| ---------- | -------------- | ---------------------- |
| **要得到什么？** | 论文的输出是什么（具体物体） | 3D网格（游戏人物模型）           |
| **困难在哪？**  | 为什么前人做不好/做不了   | 不同物体顶点数不一样，塞不进神经网络     |
| **怎么解决？**  | 用一句话说核心思路      | 先生成固定大小的"模具"，再从模具里刻出网格 |

### 第二阶段：拆解"怎么解决"（每个模块追问3个问题）

对每个提出的新概念，都问：

| 追问         | 要问什么        | 示例（四面体网格）                               |
| ---------- | ----------- | --------------------------------------- |
| **这是什么？**  | 用生活类比解释     | 像一块切成三角锥的果冻                             |
| **为什么用它？** | 不用别的行不行？    | 四面体变形后仍是四面体，好计算；立方体会变形                  |
| **怎么用？**   | 具体存什么值、怎么操作 | 每个顶点存dx,dy,dz,sdf，用marching tetrahedra切 |

### 第三阶段：串联流程（画图法）

画一个**三行流程图**：数据准备 → 训练 → 推理

每一步只写3-5个关键词，然后用箭头连起来。

**示例**：
```
真实网格 → 渲染RGBD → 拟合四面体（两轮）→ 4D张量
4D张量 + 加噪 → 3D U-Net预测噪声 → 反向传播
随机噪声 → 迭代去噪 → marching tetrahedra → 3D网格
```

### 第四阶段：追问"为什么这样设计"（逆向工程）

对每个设计选择，问：

| 问题        | 示例                  |
| --------- | ------------------- |
| 为什么选A不选B？ | 为什么用四面体不用立方体？       |
| 为什么有这个步骤？ | 为什么要两轮拟合SDF？        |
| 不加这个会怎样？  | 不归一化SDF会怎样？ → 训练不稳定 |
