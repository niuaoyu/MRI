# 07 多 AI 分工与提示词（今晚执行）

> 前提：你明天要汇报，时间只够做一件事——**把"评价漏洞"这条线做实**。所以分工不是"每人读一部分论文"，而是**每人产出一个能直接贴进汇报的构件**。
> 规则：一个 AI 只写一个文件，只写自己编号的那个，不许改 `00–06`。所有产出落到 `C:\nay\github\MRI\searchpaper\work\`。

## 1. AI-1：查新与竞争定位

**给它什么**：`03_候选问题表.md`、`04_跨域借用_形状对应.md`、`06_汇报_创新点与路线_20261030.md`
**要它做什么**：判断三个候选是不是真的空位，找反例。
**输出**：`work/01_novelty_check.md`

```
你在帮一名研二学生做硕士开题查新。背景：课题是"稀疏心脏 Cine MRI → 完整双心室表面 + 稠密点对应"，
他准备主张"这个领域所有论文都声称 dense correspondence，但没有一篇独立验证过它"。

任务：对下面三个候选创新点，逐条判断"已占位 / 半占位 / 空位"，并给出反例或支撑证据。

候选 A：对应敏感的评价协议——证明 Dice/HD/Chamfer 对顶点重新编号不变，
        用人工 landmark 测地误差 + 合成数据已知对应 + 下游 EF/EDV 效标，构成三层评价。
候选 B：薄壁方向性形变约束——沿壁厚法向的各向异性正则 + 局部单射，防止 ES 期心内膜/心外膜融合或穿透。
候选 C：形状不确定性与对应不确定性分离——证明一个方差场无法同时预测 Dice 波动与 landmark 漂移。

对每一条，必须回答：
1. 有没有论文已经做过同样的事？给出标题、年份、venue、链接。
2. 如果有，它做到什么程度？差在哪？
3. 如果没有，为什么没人做？是没人想到，还是根本做不了（数据/定义/审稿原因）？
4. 最强的反驳论点是什么？（假设你是审稿人，要拒这篇稿）

检索要求：
- 必须真的检索，不许凭记忆列举。用 Google Scholar / Semantic Scholar / arXiv。
- 关键词要给全：point identity, dense correspondence evaluation, correspondence error metric,
  landmark geodesic error, shape correspondence benchmark, thin wall myocardium, endocardial epicardial
  crossing, self-intersection mesh cardiac, aleatoric epistemic uncertainty shape correspondence。
- 中文文献也要看（知网），但不要编造。

硬约束：
- 每条结论必须带链接；没有链接的结论标"未核实"，不许写成事实。
- 不许写"近年来随着深度学习的发展"这类废话。
- 不确定就写"我不确定"，不要猜。

输出格式：
## 结论（3 行以内）
## A：已占位/半占位/空位 + 3 条证据（带链接）
## B：同上
## C：同上
## 最强反驳（针对 A，因为 A 是主线）
## 证据等级（A/B/C 各几条）
## 我没能确认的事
## 建议下一步（1 条）
```

## 2. AI-2：实验工程（今晚唯一必须出数的人）

**给它什么**：`06` 的 §3 与 §9
**要它做什么**：跑出"顶点置换后指标不变"的实证，外加 landmark 测地误差脚本。
**输出**：`work/02_eval/`

```
帮我写一个最小可运行的实验，证明"三维形状评价指标对顶点编号不敏感"。
环境：Windows + Python 3.12，可用 numpy / scipy / trimesh（没有就 pip install）。
不许用 GPU，不许下载大数据集。

实验一（必做，今晚）：
1. 生成一个椭球网格（代表心室，长轴 8cm、短轴 4cm），细分到 ~5000 顶点。
2. 复制一份，顶点顺序随机打乱（保持几何完全不变）。
3. 分别计算两个网格与"参考网格"的：
   - Chamfer distance（双向最近点距离均值）
   - Hausdorff distance（95 分位）
   - Dice（把网格体素化到 1mm 网格后算体积重叠）
4. 打印三组数，证明打乱前后完全相同（误差 < 1e-9）。
5. 画一张对比图：左=原网格，右=打乱后网格（渲染成同一颜色，视觉上应完全一样），
   下方标注三个指标的数值。存为 work/02_eval/fig_permutation_invariance.png。

实验二（有时间再做）：
1. 给椭球加一个"点身份真值"：在表面均匀取 8 个 landmark（顶点索引已知）。
2. 构造两个"形状相同但对应不同"的网格：第二个网格把顶点沿表面随机旋转一个角度
   （几何看起来一样，但 137 号顶点跑到了别处）。
3. 算 Dice/HD/Chamfer（应几乎不变）与 landmark 测地误差（应显著变大）。
4. 这张图是汇报的核心证据：形状指标看不出对应错了。

要求：
- 代码放 work/02_eval/permutation_demo.py，能一条命令跑完。
- 结果同时写一份 work/02_eval/RESULTS.md，包含：命令、三个指标的数值、结论一句话。
- 如果某个库装不上，用纯 numpy 实现（体素化用网格采样点 + 占用栅格即可），
  并在 RESULTS.md 里写明降级了什么。
- 不要美化结果。如果发现某个指标其实对编号敏感，如实写出来。

输出：代码 + RESULTS.md + 两张图。
```

## 3. AI-3：方法设计（薄壁约束）

**给它什么**：`03` 的 Q3 与 Q10、`05` 的卡 01/02/07
**要它做什么**：把"方向性约束"写成可实现的模块，不要写成综述。
**输出**：`work/03_method_design.md`

```
背景：稀疏心脏 Cine MRI 重建心肌表面，模板网格变形法在收缩末期（ES，壁厚 3-5mm）
常出现心内膜面穿透心外膜面，或两层融合导致壁厚趋零。现有论文都不报这个数。

任务：设计一个"壁厚方向性约束"模块，能插进现有的模板变形网络（例如 MorphiNet/Local2Mesh 那类），
输出要求如下：

1. 先明确定义失效：
   - 穿透：endo 顶点到 epi 面的有符号距离为负
   - 融合：壁厚 < 1mm 的顶点比例
   - 折叠：变形后网格的负 Jacobian 单元比例（若为表面网格，用三角形翻转代替）
   给出每个量的计算公式与数值统计口径（在哪些段上算、怎么处理标注噪声）。

2. 再给约束：
   - 壁厚法向怎么估计（模板上的对应点对？最近点？测地对应？）
   - 正则项写成公式：L_wall = ?
   - 与单射约束（局部 Jacobian 惩罚 / TutteNet 式分解）怎么组合
   - 权重怎么定，和 Dice 损失的权衡

3. 给最小判别实验：
   - 用 2-3 个现成 baseline，不加任何新方法，先量出穿透率（证明问题存在）
   - 加约束后再量（证明有效）
   - 报告 Dice 掉了多少（证明代价可接受）

4. 明确写出这个方案最可能失败的地方，以及失败时的退路。

硬约束：
- 不许写"引入注意力机制""多尺度融合"这类没有针对性的模块。
- 每个公式都要能落到代码，写清输入张量形状。
- 如果某个量在公开数据上根本算不出来（比如没有体网格），直接说，并给替代方案。

输出：定义 → 公式 → 实现要点 → 实验设计 → 失败模式，五节，不超过 1500 字。
```

## 8. 如果你只有一个 AI 可用

按这个顺序让它做，一个做完再做下一个：

1. 置换实验（AI-2）——**必须有数**
2. 红队（AI-5）——**保证明天不被问倒**
3. 讲稿（AI-4）——**保证讲得出来**
4. 查新（AI-1）——**锦上添花**
5. 方法设计（AI-3）——**明天之后再说，开题不要求方法已实现**

原因：汇报考的是"问题定义是否清楚、证据是否硬、退路是否想好"，不是"方法是否已设计完"。
