# 05 粗读卡片：14 篇必读的"维度流转"笔记

> 方法：`how to read a paper.md` 里的三遍法。**第一遍只画数据流**（输入张量 → 表示 → 变形 → 监督 → 输出），**第二遍把说不清的地方写成问题**，**第三遍带着问题回原文**。
> 每张卡固定八栏，其中【对应怎么来的】和【验证了什么/没验证什么】是本课题唯一关心的两栏——其余栏都是为了让你在组会上能画出流程图。
> 卡片只写**已核实**的信息。凡标"待补"的，说明公开摘要/HTML 里没有，必须拿 PDF。

---

## 卡 01 Anatomy-Aligned Surface Field Learning（2026, arXiv:2609.29825）

| 栏 | 内容 |
|---|---|
| 一句话 | 把心外膜/心内膜展开到共享 UV 域，把 3D 重建变成 2D 坐标场补全 |
| 输入 | 稀疏 SAX cine 的轮廓（不是原始像素） |
| 表示 | 共享 circumferential–longitudinal UV 域上的表面场 |
| 变形/对应 | UV 坐标天然给出跨受试者、跨时相的显式对应 |
| 监督 | 稀疏 SAX 轮廓编码为 UV 观测场；coverage-aware 采样；拓扑/畸变正则 |
| 输出 | 4D 心肌表面（epi + endo），顶点编号由 UV 网格固定 |
| 对应怎么来的 | **参数化即对应**：UV 网格的 (u,v) 就是点身份，不需要额外学 |
| 验证了什么 | 三个公开 cine 数据集上优于代表性 mesh-based 与 implicit 方法 |
| 没验证什么 | **没有单独评价对应**；没有跨数据集 landmark 误差；没有拓扑变异病例 |
| limitation 原句（A） | "Future work should employ larger external cohorts and include quantitative scar assessment, uncertainty estimation, and evaluation in downstream simulation and prognostic tasks." |
| 我的问题 | ① UV 展开在薄壁处畸变多大？② 心内膜与心外膜共享一个 UV 域，两层在 ES 期相距 3 mm，UV 上会不会重叠？③ "correspondence-aware" 这个说法有没有对应指标支撑？ |

**与方向的关系**：这是**方向 B（模板/UV 先验上限）最直接的靶子**。它把"对应"焊死在参数化上，所以参数化的畸变就是对应的误差上界。

## 卡 02 MorphiNet（2026, IEEE TMI, arXiv:2412.10985）

| 栏 | 内容 |
|---|---|
| 一句话 | 从**非配对 CT** 学心脏解剖先验，用梯度场把模板网格变形，再图细分细化 |
| 输入 | CMR（各向异性、层间距大、层间错位） |
| 表示 | 模板网格 + 梯度场（把解剖结构编码成梯度场） |
| 变形/对应 | 梯度场积分得到形变；多层图细分保持 dense point correspondence |
| 监督 | 与 CT 非配对（unpaired）；无需 CMR 的 3D 网格真值 |
| 输出 | 双心室心肌表面网格 |
| 对应怎么来的 | **模板顶点 + 细分后的子顶点**，细分规则决定新顶点的身份 |
| 验证了什么 | ToF 病人上综合 trade-off 最好：Dice 高 0.3、HD 低 2.6；ACDC 上 0.7 Dice，比模板方法提升 30% |
| 没验证什么 | CT 先验引入的**域偏移**没有量化；没报对应指标；没报薄壁穿透 |
| limitation 原句（A） | "However, accurate model reconstruction from CMR data is challenging because of its anisotropic nature." 以及 "Although fully volumetric (3D) CMR acquisitions can mitigate slice misalignment issues, it is not an imaging format that is routinely used in clinical practice." |
| 我的问题 | ① 用 CT 学先验，遇到 CT 上也不常见的病理（CHD）会怎样？② 图细分能加分辨率，但能加"模板里没有的解剖"吗？③ 非配对训练下，对应是学的还是继承模板的？ |

**与方向的关系**：方向 B 的第二个靶子，同时是"外部先验换数据域"这条路的代表。它的隐含假设是 **CT 与 CMR 的解剖分布一致**——这个假设没人验证过。

## 卡 03 Personalized 4D Whole-Heart Mesh via Multi-Scale Temporal Modeling（2026, arXiv:2607.01952）

| 栏 | 内容 |
|---|---|
| 一句话 | 端到端 image-to-mesh；Beer–Lambert 可微轮廓渲染做 2D 监督；多尺度时序模块保跨帧一致 |
| 输入 | 多视角 2D cine（SAX + LAX）**原始图像** |
| 表示 | 网格（顶点固定）+ 时序变形 |
| 变形/对应 | 模板顶点在时间轴上变形传播 |
| 监督 | 可微轮廓渲染（受 Beer–Lambert 衰减启发）把 3D 网格投影成 2D 轮廓，与图像轮廓对齐 |
| 输出 | 3D+t 全心网格 |
| 对应怎么来的 | 模板顶点；时序模块保证帧间一致 |
| 验证了什么 | 声称重建出完整心腔动力学，优于只做静态/单相/部分几何的方法（摘要级） |
| 没验证什么 | 点身份；环路闭合；薄壁 |
| limitation 原句（A） | 批评前人："They failed to model the continuous temporal dynamics and the intrinsic coupling of cardiac shape and motion throughout the cycle."；另："Most existing methods ... typically assume the availability of dense 3D geometry at a single representative time point." |
| 我的问题 | ① 可微轮廓渲染只约束**投影轮廓**，轮廓内部的点（心肌壁内、乳头肌）完全没有监督，它们的位置由什么决定？② 多尺度时序模块是平滑还是真的建模了运动？③ 帧间对应误差怎么测？ |

**与方向的关系**：可微渲染是"绕过分割"的主流路线，但**轮廓监督只给边界，不给点身份**——这正是 Q1 的入口。

## 卡 04 Bi-PT（2026, arXiv:2607.06923）

| 栏 | 内容 |
|---|---|
| 一句话 | atlas 与稀疏点云双向 cross-attention；每点语义标签；NODE 参数化局部仿射微分同胚变形 |
| 输入 | 稀疏点云（从 2D LAX/SAX 轮廓提取） |
| 表示 | atlas 点云 + 稀疏点云，双向注意力融合 |
| 变形/对应 | Neural ODE 参数化，每点一个仿射变换 + 平移，保证局部仿射微分同胚 |
| 监督 | Chamfer 距离 + 语义标签损失 + 平滑正则 |
| 输出 | 四腔网格 |
| 对应怎么来的 | atlas 点 + 每点语义标签约束 |
| 验证了什么 | 摘要级：从稀疏点云恢复四腔网格，优于 SOTA |
| 没验证什么 | 语义标签从哪来（若来自分割，则端到端性打折）；拓扑变异 |
| limitation 原句（A） | "Across these families, diverse architectures including CNN, GCN and point transformer have been adopted, but limitations remain."（这句是批评前人，自己的 limitation 段没抓到） |
| 我的问题 | ① NODE 保证微分同胚，但**离散网格**上的积分误差如何控制？② 语义标签是输入还是预测？③ 四腔之间的**边界点**（瓣环、室间隔）身份怎么定义？ |

**与方向的关系**：Q10（单射/双射）在心脏上最接近的实现，值得作为 baseline 复现。

## 卡 05 Local2Mesh（2026, arXiv:2610.06052）

| 栏 | 内容 |
|---|---|
| 一句话 | 模板网格变形；几何感知对齐纠正层间错位；plane-aware Local Router 把轮廓特征路由到模板顶点 |
| 输入 | 稀疏 2D 轮廓（M&Ms-2 / ACDC） |
| 表示 | 模板网格 |
| 变形/对应 | 基于图的模板变形；全局 + 局部轮廓特征联合引导 |
| 监督 | 轮廓点（无 3D 网格标注） |
| 输出 | 3D LV 网格 |
| 对应怎么来的 | 模板顶点 + 局部路由 |
| 验证了什么 | 两数据集几何与功能估计优于 SOTA；M&Ms-2 → ACDC 零样本迁移；重建网格改善疾病分类 |
| 没验证什么 | **只做 LV 单腔**；单帧（4D 是 future work） |
| limitation 原句（A） | "Future work will extend Local2Mesh to temporally consistent 4D reconstruction."；另："Under a local smoothness assumption, this boundary can also guide surface reconstruction in nearby unobserved regions." |
| 我的问题 | ① "local smoothness" 在 apex 处（曲率极大）成立吗？② 层间错位靠几何对齐纠正，那**没有轮廓的层间**怎么办？③ 单腔 → 四腔，路由器还能工作吗？ |

**与方向的关系**：Q6（分区误差）的直接对照。它明确说"local"，但没报分区的误差。

## 卡 06 Cardiac Mesh Flow（2026, arXiv:2605.01884）

| 栏 | 内容 |
|---|---|
| 一句话 | flow matching 一步生成多尺度自由变形场（FFD），warp 模板网格，得到 3D+t 四腔网格 |
| 输入 | 高斯噪声 + 条件（心腔体积） |
| 表示 | 模板网格 + 多尺度 FFD 场 |
| 变形/对应 | 模板顶点经 FFD 变形 |
| 监督 | flow matching 目标；条件为心腔体积 |
| 输出 | 一个心动周期的四腔网格序列 |
| 对应怎么来的 | 模板网格顶点 |
| 验证了什么 | 生成保真度、时序一致、周期一致；可条件控制 |
| 没验证什么 | 一步生成的高保真（作者自认失败）；对应 |
| limitation 原句（A） | "We then observe that Cardiac Mesh Flow fails to produce high fidelity cardiac mesh sequences within one step ..."；消融里："the highest periodic consistency is achieved as it generates static hearts and fails to capture the motion patterns." |
| 我的问题 | ① 静态心脏拿最高周期一致性——那这个指标到底在测什么？（→ Q9）② 生成模型的"对应"是模板给的，那生成多样性体现在哪？③ FFD 的网格分辨率与对应精度是什么关系？ |

**与方向的关系**：**Q9 的原弹药**。这篇论文自己把指标的漏洞写出来了。

## 卡 07 Explicit Differentiable Slicing and Global Deformation（2026, MedIA, arXiv:2409.02070）

| 栏 | 内容 |
|---|---|
| 一句话 | 显式可微体素化/切片（DVS），让 2D 切片直接监督 3D 网格；全局变形替代逐顶点变形 |
| 输入 | 稀疏 2D 切片（图像或分割） |
| 表示 | 3D 网格 + 全局变形函数 |
| 变形/对应 | 全局函数作用于网格（不是每顶点独立） |
| 监督 | 可微切片：把网格体素化再切片，与 2D 图像比较，梯度回传到网格 |
| 输出 | 3D 网格 |
| 对应怎么来的 | 网格顶点（全局变形场保持相对关系） |
| 验证了什么 | 端到端 2D→3D 监督可行；比体素路线保真 |
| 没验证什么 | 全局变形对薄壁的代价；折叠率 |
| limitation 原句（A） | "Several works resorted to using marching cubes to obtain such training datasets, thus retaining limitations of marching cubes."；"it relies on the assumption of a uniform voxel grid, which can lead to inaccuracies in representing the complex geometries." |
| 我的问题 | ① 全局变形函数在薄壁处会不会把内外膜"抹"到一起？② 体素化的分辨率与网格分辨率不一致时，梯度是否有偏？③ 可微切片能给出**点级**对应吗，还是只给形状？ |

**与方向的关系**：Q3 + Q11 的技术底座。DVS 已经解决了"2D 监督 3D"的工程问题，剩下的坑正好是薄壁与细节。

## 卡 08 TetHeart（2025, arXiv:2509.12090）

| 栏 | 内容 |
|---|---|
| 一句话 | 可变形四面体统一表示；任意数量切片；蒸馏 + 弱监督运动；覆盖全栈与术中稀疏两种场景 |
| 输入 | 全栈 CMR 或术中任意数量切片 |
| 表示 | 可变形四面体（deformable tetrahedra），多结构共享一个空间 |
| 变形/对应 | 四面体顶点变形；切片自适应 2D-3D 特征装配 |
| 监督 | 全栈预训练 → 稀疏蒸馏；弱监督运动 |
| 输出 | 4D 心脏网格（多结构） |
| 对应怎么来的 | 四面体顶点（共享空间） |
| 验证了什么 | 全栈与稀疏（低至单层）都能重建 |
| 没验证什么 | 稀疏下的对应质量；拓扑 |
| limitation 原句（A） | "this would fail to exploit temporal consistency and would make it difficult to establish inter-frame correspondences."；"a persistent challenge remains in the online scenario, where the limited number of slices can hinder accurate 3D motion reconstruction." |
| 我的问题 | ① 四面体表示天然有体积，能不能直接算 Jacobian/折叠？② 逐帧独立 vs 时序共享，环路漂移差多少？③ 单层切片时，四面体的自由度远大于观测，靠什么约束？ |

**与方向的关系**：Q5 + Q10 的最佳实验平台（有体、有 4D、有稀疏模式）。

## 卡 09 SDF4CHD（2024, MedIA, arXiv:2311.00332）

| 栏 | 内容 |
|---|---|
| 一句话 | 面向 CHD 的生成模型，把"类型（拓扑）"与"形状"解耦 |
| 输入 | 图像 + CHD 诊断标签 |
| 表示 | SDF + 类型表示模块 + 变形/修正模块 |
| 变形/对应 | 类型特定的异常 + 病人特定的形状变形与修正 |
| 监督 | 重建 + 类型条件生成 |
| 输出 | CHD 心脏解剖（可用于生成与重建） |
| 对应怎么来的 | **不提供点身份**（隐式表示），只提供形状 |
| 验证了什么 | 类型可控的生成/重建，覆盖多种 CHD；首次在表示中引入拓扑变异 |
| 没验证什么 | 对应；数据质量（imageCHD 分割噪声大） |
| limitation 原句（A） | "However, prior methods did not differentiate between type (topology) and shape changes, which can pose challenges when attempting to generate anatomies specific to particular CHDs."；"the provided ground truth segmentations were extremely noisy, posing a significant challenge in accurately differentiating the true defects from noise." |
| 我的问题 | ① 类型解耦了，但**对应**在哪？② 拓扑变异下，点身份能不能定义？③ 如果只用 SDF，下游 SSM 怎么用？ |

**与方向的关系**：Q7 的起点，也是"隐式表示换掉了点身份"的典型代价。

## 卡 11 SCorP（2024, arXiv:2404.17967）

| 变形/对应 | 流诱导的体对应（不只是表面） |
| 监督 | 重建 + 配准联合；Jacobian 行列式 + 双调和正则 |
| 输出 | 模板 + 逐例体对应 + 体素级强度映射 |
| 对应怎么来的 | 变形场（体素级） |
| 验证了什么 | 几何保真与体积对齐优于表面隐式方法 |
| 没验证什么 | 可扩展性（作者自认）；细结构 |

| 我的问题 | ① 心肌是薄壁，体对应的"内部"只有 3–5 mm，体正则还有意义吗？② Jacobian 惩罚与薄壁精度是否冲突？ |

**与方向的关系**：Q8 的现成模板。它证明了"体对应"可以做，但没在薄壁上做过。

## 汇总：这 14 篇的对应机制只有四种

| 机制 | 谁在用 | 点身份从哪来 | 失效点 |
|---|---|---|---|
| **参数化**（UV / 模板顶点） | Anatomy-Aligned、MorphiNet、Local2Mesh、Bi-PT、Cardiac Mesh Flow、Personalized 4D、TetHeart | 网格/UV 的固定编号 | 参数化畸变处（薄壁、apex、接缝） |
| **网络直接回归** | SCorP、SPI-CorrNet | 网络输出 | 无解剖约束，可能落在错误位置 |
| **变形场诱导** | SHDF、Placenta atlas、DVS | 变形场积分 | 无监督处（心肌内部、切片之间） |
| **没有对应** | STNDF、SDF4CHD | —— | 下游 SSM 无法直接用 |

**这张表就是你的 related work 的骨架。** 四种机制，四种失效点，你的选题必须落在一个失效点上，而不是再造第五种机制。
