# 06 明日汇报：创新点与路线（2026-10-30）

> 用途：开题/组会汇报。目标不是"我读了很多论文"，而是让老师相信三件事：
> ① 这个任务里有一个**被整个领域忽略的评价漏洞**；② 你有一个**便宜、可证伪**的切入点；③ 你知道**失败时怎么办**。
> 全部内容基于 `00–05` 与知识库 `status/thesis.md`。引用原句的证据等级见各条标注。

---

## 0. 一句话主张（开场就说这句）

> **"稀疏心脏 cine 重建这个领域，所有论文都声称 dense correspondence，但没有任何一篇独立验证过它——因为公开数据没有 3D 网格真值，而 Dice/HD/CD 对顶点重新编号完全不变。我的开题从证明这个评价漏洞开始，用它做 failure analysis，再针对薄壁失败提出方向性约束。"**

这句话包含四个可被检验的成分，缺一个都会被问倒：

| 成分 | 支撑 | 证据等级 |
|---|---|---|
| 所有论文都声称对应 | 10 篇 2026 心脏论文摘要逐条核对 | A/B |
| 没有独立验证 | 逐篇查 limitation 与实验节，无一篇报 landmark 或对应误差 | A（部分待补 PDF） |
| 指标对编号不变 | 可当场演示（顶点置换） | 可实验证明 |
| 薄壁是主要失败模式 | 知识库 failure 分类 + 多篇 limitation 指向各向异性/薄壁 | A |

## 2. 第 2 页的素材：为什么说"挤满了"

近两年同位置的工作（全部能在 `02` 里查到链接）：

| 方法 | 机制 | 对应从哪来 |
|---|---|---|
| Anatomy-Aligned（2026） | UV 域坐标场补全 | 参数化 |
| MorphiNet（2026 TMI） | 非配对 CT 先验 + 梯度场 + 图细分 | 模板顶点 |
| Local2Mesh（2026） | 局部路由 + 模板变形 | 模板顶点 |
| Bi-PT（2026） | atlas-点云双向注意力 + NODE | atlas 点 |
| Personalized 4D（2026） | 可微轮廓渲染 | 模板顶点 |
| TetHeart（2025） | 可变形四面体 | 四面体顶点 |
| DVS（2026 MedIA） | 可微切片监督 | 网格顶点 |
| Cardiac Mesh Flow（2026） | flow matching 生成 FFD | 模板顶点 |
| SCorP / SPI-CorrNet（2024） | 无分割图像直接回归对应（非心脏） | 网络输出 |

**结论一句话**：机制只有四种（参数化 / 网络回归 / 变形场诱导 / 无对应），两年内全被占了。**再提第五种机制，一定被问"和 XX 有什么区别"。**

## 3. 第 3 页：核心证据（这张图决定汇报成败）

**要展示的东西**：同一个预测网格，顶点随机打乱前后，Dice / HD / Chamfer 三个数**完全不变**。

```
原始网格          顶点随机置换后
Dice  0.9xx   →   0.9xx   （不变）
HD     x.xx   →   x.xx    （不变）
CD     x.xx   →   x.xx    （不变）
```

一句话解释：**这三个指标测的是"两团点云/两块体素像不像"，不是"第 137 号点是不是同一个解剖位置"。**

配套引用（A 级原句，来自 `03` / `04`）：

- Anatomy-Aligned 自称 "correspondence-aware"，future work 却写 "include ... evaluation in downstream simulation and prognostic tasks"——**对应本身没评**。
- Dense4D（2026，图形学）："4D-DRESS measures proximity to scans rather than point identity"——**别的领域已经承认这个漏洞，心脏侧还没有**。
- 2026 形状对应综述把 "Connecting quantitative metrics to downstream applications" 列为 open challenge。

## 4. 三个候选（第 4 页）

| | 候选 | 一句话 | 状态 | 成本 | 风险 |
|---|---|---|---|---|---|
| **A** | 对应敏感的评价协议 | 证明现有指标失效，给出三层替代（不变性检验 / 独立 landmark 参照 / 下游效标） | **空位**（心脏侧无） | 低（不用训练） | 被说"不算方法贡献" |
| **B** | 薄壁方向性形变约束 | 沿壁厚法向的各向异性正则 + 局部单射，防融合/穿透 | **半空位**（无专门工作） | 中（要训练） | 被说"只是加正则" |
| **C** | 形状/对应不确定性分离 | 一个方差场不能同时解释 Dice 波动与 landmark 漂移 | **半占位**（SPI-CorrNet 占了 aleatoric） | 中高 | 与既有工作撞车 |

**推荐：A 做主线，B 做方法闭环，C 后置。**

理由（要在汇报里明说）：
1. 你的论文形态是 "benchmark + 方法改进"（知识库已定），A 正好是 benchmark 那一半，不是硬凑。
2. A 便宜：不需要训练，不需要 GPU 集群，一周内能出第一张图。研二 + Java 主线并行的情况下，这是唯一现实的起点。
3. A 的产出直接是 B 的验收工具——没有 A，你无法证明 B 的约束有效。
4. C 的生态位已经被 SPI-CorrNet 占了一半，做"分离"才有差异，而分离需要 A 的两套误差度量作为前提。**所以 C 天然排在 A 后面，不是被砍掉。**

## 5. A 的三层设计（老师一定会追问"具体怎么测"）

| 层 | 做什么 | 为什么这一层不可替代 | 成本 |
|---|---|---|---|
| **L1 元评价** | 对所有被评测方法做顶点置换，证明 Dice/HD/CD 不变；再对每个指标构造"作弊基线"（静态心脏、过平滑、均匀采样） | 这是**对评价本身的评价**，无法被"你只是换了个指标"驳回 | 半天 |
| **L2 独立参照** | ① 人工 landmark 6–8 点/例 → 测地误差；② 合成数据（已知对应）验证机制；③ 四元组 cycle consistency（A→B→C→A） | 解决"没有真值"的问题：landmark 是独立于模型的；合成数据是已知答案的 | 3–5 天 |
| **L3 效标关联** | 对应误差是否预测下游 EF/EDV/应变误差 | 回答"这个指标有什么用"；也是 2026 综述点名的 open challenge | 1 周 |

**关键论证结构（写进汇报，防止被驳）**：
> 不是"我发明了一个更好的指标"，而是"我证明了现有指标在这个任务上**测不到**目标量，然后给出一个**能被独立参照校准**的替代"。

## 6. 怎么做：6 周计划 + 判据（第 6 页）

| 周 | 任务 | 交付物 | 通过判据 | 退出条件 |
|---|---|---|---|---|
| W1 | L1 元评价 | 置换 demo + 作弊基线表 + 3 个 baseline 的原始输出 | 至少 2 个指标被作弊基线打败 | 若所有指标都稳健 → A 不成立，转 B |
| W2 | landmark 协议 | 20 例 × 6–8 点标注 + 测地误差脚本 | 两个 Dice 相近的方法，landmark 误差差 2 倍 | 若两者高度相关（Spearman > 0.8）→ 指标不成立 |
| W3 | 全量评测 | 15 方法 × 3 稀疏度表 | 出现稳定的"形状好但对应差"集群 | 若无此集群 → 转 B |
| W4 | failure analysis | failure_analysis.md（薄壁/尖端/RV/塌陷/拓扑） | 薄壁失败被量化（穿透率或腔体闭合率） | 若薄壁不是主因 → 换失败模式 |
| W5 | B 的方法 v1 | 方向性正则 + 单射约束 | 穿透/折叠降一个量级，Dice 掉 < 0.5 点 | 若精度代价过大 → 只保留评价论文 |
| W6 | 写作 | 开题报告 / 论文初稿 | 老师能复述你的主张 | —— |

**注意 W1 的退出条件**：如果置换 demo 发现某个指标其实对编号敏感（例如某些论文报的是逐顶点误差），A 的立论就要修正。**这个风险必须在汇报里主动说**，比被老师问出来强。

## 7. 第 8 页：需要老师拍板的三件事

1. **论文形态**：是否接受"评价协议 + 一个方法改进"的组合？还是必须方法为主？
   （影响：A 能不能当主线。）
2. **对应真值的边界**：人工 landmark 只覆盖 6–8 点，合成数据只有机制意义。老师是否认可这个证据强度？
   （影响：A 的结论能说多硬。）
3. **薄壁优先还是 4D 优先**：薄壁（B）方法难但差异化强；4D 环路闭合（Q5）便宜但天花板低。
   （影响：W5 之后做什么。）

## 8. 预判 10 个提问 + 答案

| # | 老师可能问 | 怎么答 |
|---|---|---|
| 1 | 别人已经报过 landmark 误差，你凭什么说没人验证？ | 在**稀疏 cine 心脏重建**这个子领域，因为没有 3D 网格真值，主流论文用形状指标替代；SSM 领域有 landmark，但输入是完整分割、不是稀疏切片。边界要说清。 |
| 2 | 你的指标和 geodesic error 有什么区别？ | 没有区别，landmark 测地误差就是 L2 的一部分。我的贡献是**证明现有评价失效** + **三层协议**，不是发明新距离。 |
| 3 | 20 例 landmark 太少 | 少，但足以做**排序**，不足以做绝对精度。结论只声称排序，不声称绝对误差。 |
| 4 | 顶点置换是伪问题，实际模型不会输出乱序顶点 | 对，实际不会。但指标的不变性说明它**在原理上**不检验身份；真实情况是"点身份错了但形状对"，置换只是把这个盲区放大到可见。 |
| 5 | 这只是 benchmark，不算创新 | 论文形态本来就是 benchmark + 方法改进；而且 L1 是**对评价的评价**，B 是方法改进，两者构成闭环。 |
| 6 | 薄壁穿透会不会是标注问题？ | 会。所以先做参考标签壁厚审计（<1 像素的段先剔除），再统计穿透。已在计划里。 |
| 7 | 隐式方法根本不会穿透 | 对，所以指标按方法族分开：显式模板测穿透/折叠，隐式测腔体闭合与壁厚分布。 |
| 8 | 你的方法和大模型/基础模型什么关系？ | 现阶段不用。基础模型解决"语义先验"，不解决"点身份"；而且稀疏 cine 不在其训练分布内。作为 future work。 |
| 9 | 一年做得完吗？ | W1–W3 是评价，纯 CPU，4 周；W4–W5 是方法，复用已有 baseline 代码。最坏情况只交评价论文，仍然成立。 |
| 10 | 如果实验结果全部阴性怎么办？ | 阴性结果本身就是结论："现有指标与对应质量无关"——这正好支撑 A 的立论。负结果保留，写进 failure analysis。 |
