# 检索方法与粗读法

> 本目录是一次「按对手定位，而不是按关键词定位」的文献检索产物。
> 目标不是把心脏重建的论文都列出来，而是回答：**谁在抢「隐式模板 + 密集点对应」这个位置，他们还没解决什么。**

---

## 0. 检索的课题定位（来自知识库）

| 项 | 内容 |
|---|---|
| 任务 | 稀疏 Cine MRI（切片轮廓/分割）→ 患者特异性完整双心室表面 + **密集点对应** |
| 最终目标 | 任意分辨率的**隐式模板**心脏三维重建与密集点对应（覆盖 LV 心肌内外壁 + RV） |
| 基线 | MR-Net、NDM（Neural Deformable Models，双心室版） |
| 当前阶段 | 开题：从基线的机制、假设、适用边界出发，凝练至少三个可验证的方法问题 |
| 三个候选方向（知识库 2026-10-24，明确标注为 AI 辅助候选、未确认） | ① 弱解剖约束下，连续模板点身份如何独立验证；② 薄壁方向性形变约束如何兼顾几何合理与患者差异；③ 稀疏观测下，形状不确定性与对应不确定性如何区分评价 |

**筛选口径因此不是「心脏 + 重建」，而是：**

1. 是否使用 **template / canonical shape**；
2. 是否声称 **dense correspondence / point identity**（而不只是表面像）；
3. 是否处理 **sparse / anisotropic / partial 观测**；
4. 是否给出 **对应质量的证据**（而不是只有 Chamfer / Dice / HD）。

四项里命中 3 项以上，才算「同一位置的对手」。

## 1. 四条检索路线（本次实际执行）

### 1.1 反向引用链：先找引用基线的论文

比关键词更准，因为抢同一个位置的论文**必须**引用基线。

| 种子 | OpenAlex ID | 2024 年以来引用数 | 说明 |
|---|---|---|---|
| MR-Net: Multiresolution Deep Implicit Functions for 3D Shape Representation (2021) | W3200254434 | 12 | 多分辨率隐式表示基线 |
| NDM: Neural Deformable Models for 3D Bi-Ventricular Heart Shape Reconstruction... (2023) | W4390872602 / W4384643732 | 4 / 1 | 心脏版 NDM；OpenAlex 有两条重复记录 |
| DIF-Net: Deformed Implicit Field (2021) | W3175010717 | 69 | 隐式模板 + 学习到的 dense correspondence 的源头之一 |
| DIT: Deep Implicit Templates (2021) | W3174726247 | 46 | 模板空间 + 变形 |
| Shape registration with learned deformations (2021) | W3200745935 | 35 | 稀疏/不完整点云 + 学习变形，心脏邻近 |

> 注：OpenAlex 的引用数普遍低于 Google Scholar（MR-Net 在 OpenAlex 总引用仅 41）。因此这里只用它做**召回**，不用来判断论文影响力。引用数低于 Scholar 是预期现象，不代表漏检。

### 1.2 拼接限定词：把范围压到近两年

实际执行的查询（OpenAlex `title_and_abstract.search`，`from_publication_date:2024-01-01`，按引用数排序取前 200）：

| 组合 | 命中 | 有效信号 |
|---|---|---|
| cardiac + dense correspondence | 16 | 高（Local2Mesh、Anatomy-Aligned、MorphiNet、Adaptive Bi-ventricle） |
| cardiac + template + implicit | 7 | 中（cMeta-INR、image-to-mesh 综述） |
| cardiac + shape correspondence | 33 | 中（STNDF、Bi-PT、VecHeart） |
| cardiac + mesh reconstruction + sparse MRI | 14 | 高（CineMesh4D、Explicit differentiable slicing、TetHeart） |
| heart + implicit template | 24 | 低（"heart" 一词歧义大） |
| cardiac + digital twin + mesh | 43 | 中（biv-me、4D whole-heart、digital twin pipeline） |

关键词法的噪声很大（"heart" 会命中大量临床/人文论文），所以最终清单以**引文链 + 方法学筛选**为准，关键词只用来补漏。

### 1.3 采摘 limitation 段

对每篇候选：

1. 先找 arXiv 版（很多 MICCAI/TMI/MedIA 论文都有）；
2. 抓 arXiv HTML 全文；
3. 抽 `Limitation / Future work / Discussion / Conclusion` 章节；
4. 再全文扫描含 `limitation / future work / we do not / cannot / assume / remains / challenge` 的段落；
5. 一句一条进候选问题表，附原句与链接。

**证据分级（贯穿本目录）：**

| 级别 | 含义 |
|---|---|
| A | 原文全文原句（arXiv HTML 可核） |
| B | 仅摘要/出版社摘要页 |
| C | 仅题名/二手描述，**不得**当作论文结论引用 |

### 1.4 跨域借用：通用 3D 视觉里已经解决的问题

查询：`bijective / injective / homeomorphism / point identity / diffeomorphic template / correspondence uncertainty / non-rigid shape matching`，限 2024 年起。

重点不是"看看别人做什么"，而是找**能直接搬过来的约束或评价方式**：单射变形、双射映射、规范空间、对应不确定性、部分-部分匹配。

## 2. 数据源与替代说明

| 想要的 | 实际用的 | 原因 / 局限 |
|---|---|---|
| Google Scholar「cited by」 | OpenAlex `filter=cites:W...` | Scholar 无公开 API 且强反爬；OpenAlex 覆盖大部分期刊/会议，但引用数偏低、2026 年新论文收录滞后 |
| 论文全文 | arXiv HTML | 只有挂了 arXiv 的能抓；Elsevier/Springer 付费全文抓不到，对应条目标 B/C |
| 摘要 | OpenAlex → Crossref → Semantic Scholar | 三家互补；仍缺的标"摘要未获取" |
| 最新预印本 | arXiv API | 2026 年部分论文只有 arXiv 版 |

**结论：这份清单适合做"对手地图"和"问题候选"，不适合做"查新报告"。** 正式开题前，至少要把 Top 10 对手的全文（尤其 Limitation 节）亲自读一遍，并把 B/C 级证据升级为 A 级。

## 3. 粗读法（本目录实际使用的）

### 3.1 第一遍：粗跑通（知识库「维度流转法」的第一遍）

不追求读懂公式，只抓一条端到端链路：

```
输入（稀疏切片/轮廓，形状？）
  → 表示（模板网格 / 隐式 SDF / 混合）
  → 对应从哪来（模板顶点编号 / 变形场 / 功能映射 / 后处理）
  → 监督（3D GT？2D 轮廓？弱监督？）
  → 输出（网格？SDF？4D？）
  → 评价（Dice/HD/Chamfer？对应误差？下游指标？）
```

只要这条链路说不清，就还没粗读完。

### 3.2 五问筛选（来自 `how to read a paper.md`）

1. 这个方向的背景是什么？
2. 目前难点是什么？
3. 为解决难点，当前有哪几条研究路线？
4. 这些方法**牺牲了什么**换来进展？
5. 我打算跟进哪条？

第 4 问是关键：对手的"代价"往往就是你论文的位置。

### 3.3 本目录的粗读卡片（见 `05_粗读卡片.md`）

每篇对手只填 7 格：

| 字段 | 要回答什么 |
|---|---|
| 问题 | 它声称解决什么（一句话） |
| 表示 | 模板网格 / 隐式 / 混合；对应是原生的还是后处理的 |
| 对应 | 点身份怎么定义、怎么保证、有没有独立验证 |
| 监督 | 3D GT / 2D 轮廓 / 弱监督 / 无监督 |
| 证据 | 数据集、指标、有没有对应指标 |
| 限制 | 原文 limitation 原句（标 A/B/C） |
| 对我的威胁 | 它已经占了我哪个候选问题；我还剩什么空间 |

### 3.4 推荐使用顺序

1. 扫 `01`、`02` 的标题，圈出与你方向重叠的 10 篇；
2. 用 `05` 的卡片粗读这 10 篇（每篇 10–15 分钟）；
3. 用 `03` 的候选问题表挑 3 个，逐个查"是否已被做"；
4. 用 `04` 找可借的约束/评价方式；
5. 只对最终 3 篇做精读（知识库 `skills/close-read-paper.md`）。

## 4. 复现

脚本在 `_scripts/`，原始数据在 `_raw/`：

| 脚本 | 作用 |
|---|---|
| `resolve.py` | 按标题在 OpenAlex 定位种子论文 |
| `citations.py` | 拉种子的 2024+ 引用论文 |
| `search_topics.py` | 跑组合限定词查询 |
| `shortlist.py` | 去重、打分、生成候选池 |
| `details.py` / `crossref_fill.py` | 补摘要与元数据 |
| `arxiv_fetch.py` | 找 arXiv 版并抽 limitation 段 |

运行环境：Python 3.12，仅标准库；OpenAlex 免密钥。
