# 组合限定词检索（2024–2026）

> 全部查询限 `from_publication_date:2024-01-01`，数据源 OpenAlex，按引用数排序取前 200 后人工筛。

**结论：`cardiac + template` 这一路的关键词召回最差。** 真正同位置的论文更常用 `atlas / canonical / UV domain / point identity / deformation field`，而不是 `template`。这也是为什么必须做引文链和跨域检索。

## 3. 关键词路线的盲区（必须靠引文链和跨域补）

1. **不叫 template 的模板**：`atlas`、`canonical space`、`UV domain`、`mean shape`、`statistical shape model`。
2. **不叫 correspondence 的对应**：`point identity`、`vertex-wise correspondence`、`registration`、`cycle consistency`、`functional map`。
3. **2026 年的 arXiv 预印本**尚未被 OpenAlex 完整收录，只能靠 arXiv 直接搜。
4. **负面结果**：关键词检索天然只返回"声称解决了"的论文，失败案例要靠 limitation 段和综述。

## 4. 已排除的噪声类型

| 类型 | 例子 | 排除理由 |
|---|---|---|
| 纯临床预后/器械 | MACE 预测、TAVR、消融 | 不做形状表示与对应 |
| 数字孪生仿真 | 电生理求解器、血流仿真 | 用现成网格，不研究重建/对应 |
| 纯分割 | 各种 CMR 分割网络 | 不输出点身份 |
| 统计形状模型（SSM） | 传统 PCA 形状模型 | 对应由配准给定，通常不作为方法贡献；但**评价口径可借** |
| "heart" 歧义 | 人文/天文/生物论文 | 与课题无关 |
