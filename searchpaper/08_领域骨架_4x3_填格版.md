## 一、先把三个承诺拆开（这张表最值钱的一行）

你以为的"对应好不好"，其实是三个独立的东西，必须分开验收：

| 承诺 | 在问什么 | 有成熟指标吗 | 有真值吗 | 谁在测 |
|---|---|---|---|---|
| **C1 形状准不准** | 轮廓、体积、壁厚像不像 | 有：Dice / HD95 / CD / ASD | 有（分割标签） | 所有人 |
| **C2 点身份可不可信** | 137 号点是不是同一解剖位置 | 没有统一口径 | **没有**（无 3D 网格真值） | 几乎没人 |
| **C3 换密度稳不稳** | 查询密度/切片数变了，结果变不变 | 没有 | 可以自己造 | 几乎没人 |

**一句话结论：C1 已经卷死了，C2 和 C3 是空的。你觉得乱，是因为把"方法里的对应"和"评价里的对应"混成了一个词。**

## 二、四层：从采集到评分

```
L1 输入           L2 表达             L3 形变与对应        L4 输出与评价
─────────         ─────────          ─────────────       ─────────────
SAX/LAX 切片  →   显式 mesh/atlas  →  模板 + warp     →   marching cubes
分割/轮廓         隐式 SDF/occupancy   对应从哪来           Dice/HD/CD
层厚/层间距       连续场查询           拓扑/自交            跨患者 vs 同患者
     │                  │                  │                   │
     └── 稀疏在哪一维 ──┴── 有没有编号 ────┴── 谁定义身份 ─────┴── 谁来判对错
```

**关键分界**：L2 决定"有没有点身份"，L3 决定"点身份怎么来"，L4 决定"点身份算不算数"。三段是串联的，任何一段断了，后面都白做。

## 三、4×3 填格表

### L1 输入：我手里到底有什么

| | 有人做了 | 没人做 / 做不动 | 一句话 |
|---|---|---|---|
| **C1** | 全部方法都吃稀疏 SAX；DVS 直接用 2D 切片监督网格；TetHeart 支持任意数量切片，低至单层 | —— | 输入端已经标准化，没有创新空间 |
| **C2** | SCorP / SPI-CorrNet 从**未分割**图像直接给对应；Improved 3D Whole Heart 自认"依赖分割"是限制 | 没人证明"不用分割"的对应是否解剖正确 | 输入是否分割，决定了对应是学出来的还是继承来的 |
| **C3** | TetHeart 报"低至单层"；多数论文只报一个稀疏度 | **没有一篇报"输入密度 → 输出稳定性"的曲线** | 这是 C3 最便宜的入口 |

> 你的数据：UKDH（1331 静态）、M&Ms-2（4D 多中心）、4DM（LV 先验）、ACDC（仅评估）。**稀疏度可以自己造**：从完整堆栈里删层，这就是 C3 的实验台。

### L2 表达：形状用什么存

| | 有人做了 | 没人做 / 做不动 | 一句话 |
|---|---|---|---|
| **C1** | 隐式：DeepSDF / DIF-Net / NDM / STNDF / SDF4CHD；显式：AtlasNet / MR-Net / Slice2Mesh / MorphiNet | 隐式与显式在同一稀疏度下的系统对比 | 这是你 benchmark 的主表 |
| **C2** | 显式模板天然有编号（MorphiNet、Local2Mesh、Bi-PT）；隐式**天然没有**（SDF4CHD、STNDF 不输出对应） | **隐式表示如何拿回点身份**，且不退回模板 | 表达形式直接决定 C2 是否存在，这是整张表的枢纽 |
| **C3** | 隐式号称"任意分辨率"；显式靠图细分加密 | 两者都只增加**采样密度**，不增加**信息**；没人量化这个差别 | "任意分辨率 ≠ 任意细节" |

**最容易搞混的一条**：隐式的"无限分辨率"是**查询分辨率**，不是**信息分辨率**。输入只有 8 层切片，查询到 1 μm 也不会变出乳头肌。

```
信息漏斗（这张图要在汇报里画出来）

真实解剖细节  ████████████████
分割/轮廓     ██████████          ← 层厚 8mm，层内 1mm
网络容量      ███████
查询密度      ████████████████████  ← 可以无限大，但只是把上面那一行采样得更密
────────────────────────────────
能恢复的细节  ██████████          ← 由最窄的一环决定
```

### L3 形变与对应：点身份怎么来

| | 有人做了 | 没人做 / 做不动 | 一句话 |
|---|---|---|---|
| **C1** | 形变场（NDM/DIF）、NODE（Bi-PT）、FFD（Cardiac Mesh Flow）、可微切片（DVS） | 大变形下的稳定性 | 方法层已经挤满，别再提第五种机制 |
| **C2** | **四种来源全部被占**：参数化（UV/模板）、网络回归（SCorP/SPI-CorrNet）、变形场诱导（SHDF/Placenta/DVS）、无对应（STNDF/SDF4CHD） | 无模板 + 有点身份，这两件事没人同时做到 | 这是你"方法层无空位"的证据 |
| **C3** | 单射：TutteNet、Jacobian 惩罚、Bi-PT 的微分同胚；拓扑变异：SDF4CHD、GrowFields | 薄壁处的折叠/穿透没人量化 | 这是 B 方向的入口 |

---

### L4 输出与评价：怎么算对

| | 有人做了 | 没人做 / 做不动 | 一句话 |
|---|---|---|---|
| **C1** | Dice / HD95 / CD / ASD，全部成熟；biv-me 做多中心外部验证 | —— | 已经卷死 |
| **C2** | 个别论文用 landmark 或 cycle consistency（SSM 领域、图形学），心脏稀疏重建里几乎为零 | **没有独立参照，没有统一协议** | **这是全文的空位** |
| **C3** | 无人系统报告 | 换查询密度/切片数的稳定性曲线 | 最便宜的一张图 |

**C2 的空白具体长什么样**：

```
论文里写的                     实际测的
────────────                  ────────
"dense correspondence"   →    Dice 0.91
"point identity"         →    HD95 4.2mm
"anatomical alignment"   →    CD 1.8mm
                              ↑ 这三个数，把顶点随机打乱后一个都不变
```

| **Personalized 4D** | 2026 | 多视角 cine | 网格 | 可微轮廓渲染 | 几何 | L1-C1：绕过分割 | 轮廓内部无监督 |
