# Benchmark 方法目录

> **实现状态说明：** 本文件描述研究目标、候选方法和未来实验协议；它不是当前运行能力的完整承诺。现阶段优先保证已有 adapter 可以在 MNMS2/UDH 上完成训练。ACDC 的输入格式可以保留，但其测试场景、缺失协议和评估方式待单独确定，不应套用 MNMS2/UDH 的协议。

## 当前实现边界

当前阶段只把以下内容作为硬性要求：

- 方法配置能够通过 registry 加载；
- 对应 paradigm 方法实现 能被构建；
- 训练 Dataset 能读取已有 `preprocessed/` archive；
- runner 能创建实验目录、保存配置和 checkpoint，并完成训练 phase；
- MNMS2/UDH 的 ED/ES 配对和必要训练字段由 `doctor --check-data` 校验。

完整的 observation robustness、统一排行榜、拓扑/体积/碰撞指标、生成式统计和 ACDC 专属测试协议，暂时属于后续协议，不作为当前训练链路的前置条件。

## 研究范围与任务协议

本项目研究**对象级三维几何重建**，具体任务是从稀疏 CMR 轮廓恢复患者特异性完整心室形状，并获得可评价的闭合表面：

```text
sparse CMR contours + slice geometry (+ structure labels)
    → complete patient-specific 3D shape
    → reliable ventricular surface / mesh
```

训练阶段可以使用完整表面、分割、隐式场采样、对应关系等额外信息；测试时只能使用上述协议输入。方法应满足：

1. 输出当前患者的完整几何，并与已观测轮廓一致；
2. 能补全切片之间和视野外的未观测区域；
3. 直接输出表面，或输出可稳定提取表面的 SDF、occupancy、UDF、point cloud、voxel、segmentation、mesh 或混合表示；
4. 支持所需结构，并可评价闭合性、拓扑和结构相交等表面性质。

文献候选范围包括对象级 **3D shape/surface reconstruction and completion**。原始输入可以是 contour、point cloud、image、depth、voxel 或 partial surface，也不要求已有代码；只要核心方法能够合理改造成 contour-conditioned reconstruction，就可纳入。以场景外观、新视角合成或 rendering 为主要目标，且不能稳定恢复完整对象表面的方法不纳入。

## 分类与筛选原则

目录按便于阅读的三级结构组织：

1. **重建方式：** Direct reconstruction；Template/deformation reconstruction。
2. **表示：** Implicit（以 SDF、Occupancy 为主）；Explicit（mesh、point cloud、voxel/label volume、参数化表面）；Hybrid（连续场与可学习离散结构共同决定几何）。
3. **推理：** Encoder–Decoder；AutoDecoder；Instance fitting / Direct fitting。

固定 Marching Cubes 等值面提取不改变 Implicit 归属；DMTet、MeshDiffusion 等同时预测场值和可变离散结构的方法归 Hybrid。`Template/deformation` 指共享解剖模板、canonical shape、统计模型或参数化 primitive 的形变，不等同于 AutoDecoder。

树状目录只用于定位方法，实验分析采用以下正交维度：

- direct vs template/deformation；
- implicit vs explicit vs hybrid；
- SDF vs Occupancy；
- global vs spatial/local condition；
- feed-forward vs test-time optimization；
- deterministic vs generative；
- free topology vs topology/correspondence preserving；
- no prior、解析正则、SSM、atlas/template、learned population prior、generative prior；
- deep learning vs non-learning optimization。

方法选择遵循四项原则：

1. **任务优先：** 测试时必须只使用 `sparse CMR contours + slice geometry + structure labels`，并恢复患者特异性完整闭合表面。
2. **代表优先：** 主线聚焦 SDF、Occupancy、显式模板形变和 DMTet 类混合表示；小众表示采用例外制，不全面复现。
3. **避免重复：** 同一表示、condition、decoder 和推理机制只保留少量代表；任务原生方法优先于需要大幅改造的通用方法。
4. **适配可追溯：** 允许确定性输入转换、替换 condition encoder、加入结构标签和轮廓一致性约束，但不能用另一套网络替代原论文的核心重建机制。

### 协议与实验角色

- **P0：** 原方法的测试输入和输出与当前任务基本一致。
- **P1：** 经合理适配后可进入统一协议，并保留原方法核心机制。
- **Task-native：** 原生 cardiac sparse-view/contour reconstruction。
- **Controlled：** 用统一 contour condition 构建的通用方法受控对照。
- **Diagnostic：** 无 population prior 或能力受限的诊断基线，不作为预期最优补全方法。
- **Official branch：** 原论文或官方仓库提供的扩展分支，如 IGR、DiGS 的 shape-space AutoDecoder。
- **Project variant：** 本项目为统一协议构造的适配或消融，不视为原论文方法。

表格统一为 7 列：`方法 | 论文 / 发表 | 表示 | 范式 | 核心机制与测试推理 | 角色 / 适配与限制 | 代码 / 状态`。先按推理/生成范式分组，再按技术亲缘排序。状态为 `已集成`、`计划复现`、`待确认` 或 `不复现`；副表保留不复现方法及必要原因，不删除方法谱系。

## Benchmark 分层与候选集

当前目录共收录 **192 个方法**：主表候选 31 个，副表 161 个。主表 31 个方法已经是按任务适配性、谱系代表性、比较价值与可复现性筛选后的 benchmark 候选集，不再额外划分缺少独立判定标准的“核心方法”子集。

主表候选不等于所有方法均进入同一排行榜。方法完成统一输入适配、训练与推理预算对齐、输出 mesh 验证和可复现性检查后，才进入最终执行集；这是实施状态，而不是另一层文献筛选。表中的 `已集成`、`计划复现` 和 `待确认` 用于记录这一过程，`Task-native`、`Controlled`、`Diagnostic`、`Official branch` 和 `Project variant` 用于区分实验角色。

当前没有满足静态 contour-only 协议且可公平复现的 `Template/deformation + Hybrid` 主表方法；不为填补分类格而引入弱适配路线。

结果建议分三组报告：

1. **任务原生主结果：** cardiac P0 方法，以及 Algebraic Sphere Surface Fitting、OReX、CrossSDF cross-section 基线；
2. **受控技术比较：** 统一 condition、训练预算和后处理下比较表示、先验与生成范式；
3. **诊断/消融：** IGR/IGR shape-space AutoDecoder 与 DiGS/DiGS shape-space AutoDecoder 两组配对，以及 DMTet/MeshDiffusion、LC-U-Net/CardiacFlow 配对实验。

优先复现任务原生方法和不可替代的对照。LoSF-UDF、CoFie、DCC-DIF 等缺少全局 completion 能力的方法保留在副表；PCCN 等依赖额外点云到 mesh 后处理的方法不进入主表候选集。`Mask2Surface` 主要解决 mask 修复，超出当前协议。

## 统一评测协议

### 输入与任务设置

- 主协议只允许测试时使用 `sparse CMR contours + slice geometry + structure labels`。原方法需要 image/voxel/point cloud 时, 只能通过确定性转换得到对应输入；不得引入测试患者的完整分割、完整体数据或参考 mesh。
- 所有方法使用相同物理坐标系、spacing、结构标签、训练/验证/测试患者划分和观测轮廓。数据划分必须按患者完成, 禁止同一患者的不同时相跨集合泄漏。
- 至少报告 4 种视图设置：`SAX only`, `SAX + 2CH`, `SAX + 2CH + 4CH`, `all available views`。每种设置再报告 100%、50% 和 25% 的切片保留率；最低切片数由各结构可见性约束统一确定。
- 鲁棒性实验分别加入 slice 平移误差 0/2/5 mm、旋转误差 0/2/5 deg、轮廓法向抖动 0/1/2 mm, 以及 0%/10%/25% 的轮廓或结构标签随机缺失。扰动使用固定随机种子并对所有方法共享。
- 数据允许时, 分别报告健康、常见病理、罕见病理、跨中心/扫描仪和未见病理 OOD 子集；静态重建是主任务, 4D 时序、术中更新和 raw-image condition 只作为扩展协议。

### 几何、拓扑与一致性指标

- **表面精度：** 按结构报告 ASSD、symmetric Chamfer distance、HD95 和 normal consistency, 同时给出 macro average, 避免大结构主导结果。
- **观测一致性：** 报告 contour-to-surface 双向距离、预测表面与原切片平面的交线误差, 以及按 slice/view 分组的误差；该指标必须在原始物理坐标中计算。
- **体积一致性：** 对可闭合表面统一栅格化后报告 Dice、relative volume error 和临床相关容积/质量误差；栅格分辨率对所有方法固定。
- **表面合法性：** 报告 watertight rate、2-manifold rate、connected components、Euler characteristic/genus、法向一致性、自相交数量/面积和 inter-structure collision。
- **网格质量：** 对显式或体积网格补充 edge-length distribution、triangle aspect ratio、minimum angle；四面体输出另报 scaled Jacobian、dihedral angle 和 inverted-element rate。
- **效率：** 报告参数量、训练成本、单例 wall-clock time、test-time optimization 迭代数、峰值 CPU/GPU memory 和表面提取/后处理时间。

### 生成式方法与统计报告

- `生成式-重建即生成` 方法固定采样数 `K`, 主报告使用 `K=8`, 并补充 `K=1/4/16` 敏感性。必须同时报告 expected error、best-of-K、样本间 diversity、coverage 和每个样本的观测一致性；不得只报告 best-of-K。
- `生成式-latent增强` 方法首先报告相同 deterministic reconstruction backbone 的 `without vs with generative enhancement` 配对消融, 统一训练样本数、优化预算和后处理。若生成模块只用于训练增广, 至少使用 3 个生成数据随机种子；若测试时仍采样 latent/prior, 再按 `K=1/4/8/16` 报告敏感性。
- 不确定性校准使用逐点或逐结构误差与预测方差/置信区间的关系评估, 并报告 calibration curve 或 ECE-style 汇总。非生成式方法按 `K=1` 进入相同精度表, 不伪造 diversity 指标。
- 所有主指标报告 patient-level mean、median、standard deviation 和 95% bootstrap confidence interval；主要方法比较使用配对检验并报告 effect size, 不只报告 p-value。

### 公平性与后处理约束

- 统一训练数据、输入采样、坐标归一化、query/point 数量、表面采样点数和评测实现。方法特有超参数可调, 但调参预算和验证集固定并公开。
- Marching Cubes、Poisson/Ball Pivoting、smoothing、hole filling、component filtering 等后处理必须逐项记录。主结果优先报告原方法必要后处理；额外修复结果单列, 不得用未声明的拓扑修复替代方法本身。
- Template 方法使用同一训练集构建模板/SSM, 并同时报告总体误差与对异常病理的 template bias。Instance fitting 方法统一初始化数量、最大迭代数和时间预算。
- 每个方法至少记录 3 个失败维度：未观测区域 hallucination、薄壁/尖端缺失、结构碰撞或拓扑错误。最终结论按研究路线汇总, 不以单一综合分数掩盖临床和几何失败。

# 2. Template/deformation reconstruction

## 2.1 Implicit representation

模板隐式形变主线当前采用 SDF, 不是因为 Occupancy 不可用。canonical Occupancy 也可以经形变场得到目标场, 但模板注册与拓扑保持需要连续的有符号几何信号、表面法向和稳定的测试时优化梯度; SDF 的零等值面、距离梯度以及 Eikonal/形变正则更直接, 因而在该路线中更常见。严格地说, 非刚性 warp 后的场不一定仍是精确距离函数, 但可通过 Eikonal 或重初始化维持 SDF 性质。Occupancy 主要放在 Direct completion 中作为主流对照; 不为填补分类格而强行加入一个需要大幅改造且缺乏公平复现条件的模板 Occupancy 方法。
